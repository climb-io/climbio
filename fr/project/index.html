Guides d’utilisation

Intégrer Climbio à l’appli de votre salle

Avec l’agent IA que vous utilisez déjà, ajoutez l’affichage et la création de voies à l’appli existante de votre salle, sans développement séparé. Cette page explique le principe ; les spécifications et les étapes d’intégration sont sur GitHub.

Ce qui est disponible

Hold Cat permet de créer et partager des voies. Redpoint Cat permet de télécharger des données de falaises pour les consulter hors ligne. Le partage entre amis, le collecteur et Studio facilitent l’organisation des données. Les outils évoluent encore.

Suivre les avancées

Les changements de la version publique sont visibles sur GitHub. Les projets et les tâches inachevées restent dans les suivis du projet, sans être présentés ici comme terminés.

Activité de développement

Intégrer avec votre agent IA

Demandez à votre agent de lire d’abord le guide d’intégration. Trois étapes : préparer et publier le mur dans Studio, placer les écrans de visualisation et de création dans l’appli, puis mettre à jour les voies avec un identifiant de mur fixe. Convient aux salles qui aiment partager leurs voies avec les grimpeurs. La correspondance entre vos utilisateurs et les voies relève de votre appli ; Climbio n’intervient pas.

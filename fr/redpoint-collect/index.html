Collecteur Redpoint Cat

  1. 01

    Installer dans Chrome

    Ouvrez la page du Chrome Web Store dans Chrome sur ordinateur et cliquez sur « Ajouter à Chrome ». L’extension apparaît dans la barre d’outils et se met à jour automatiquement.

  2. 02

    Enregistrer une falaise

    Sur une page de falaise compatible, cliquez sur « 紅點貓收藏 » dans la barre d’outils Chrome. L’extension ouvre Redpoint Cat sur l’ordinateur et importe les voies et les topos.

  3. 03

    Synchroniser avec le téléphone

    Connectez les deux appareils au même Wi-Fi permettant la communication directe et ouvrez Redpoint Cat sur chacun. Associez-les via le profil et « Mes appareils », synchronisez, puis vérifiez les photos et les topos avant de partir.

Sites compatibles ?

theCrag, Hong Kong Climbing, OpenClimbing et les sites offrant des données Climbio. Toutes les pages ne disposent pas de topo.

Où sont les données ?

Vos données sont enregistrées localement dans Redpoint Cat, sans compte. Respectez les licences d’origine avant toute redistribution.

Comment mettre à jour ?

La version du Chrome Web Store se met à jour automatiquement.

Pour commencer

Depuis l’accueil, ouvrez « Monde » avec l’icône du globe, puis choisissez le pays, la région et la falaise. Téléchargez le guide et ouvrez les topos nécessaires avant de partir. Testez en mode avion pour confirmer que les photos sont disponibles hors ligne.

Installer l’application

Redpoint Cat est une application web progressive. Sur iPhone/iPad : Safari → Partager → Sur l’écran d’accueil. Sur Android : Installer depuis Chrome. Sur iOS, l’app installée et le navigateur peuvent avoir des données locales séparées ; vous devrez parfois retélécharger des guides.

Trouver des falaises

« Monde » présente des cartes par pays, régions et falaises. Il réunit des guides publiés via Climbio et des données OpenClimbing disponibles. Ce n’est pas un catalogue exhaustif et toutes les falaises n’ont pas de topo photo. Vous pouvez aussi utiliser un lien reçu, l’outil de collecte sur ordinateur ou un fichier local.

Télécharger pour le hors ligne

Téléchargez intégralement le guide, ses photos, voies et cartes disponibles. Ouvrez vos topos et contrôlez les avertissements concernant les images manquantes. Seules les données effectivement téléchargées sont accessibles hors connexion ; nouveaux sites, import web et navigation externe nécessitent Internet.

Parcourir une falaise

Sur l’accueil, sélectionnez une carte de falaise puis une paroi pour ouvrir le premier topo. Balayez pour changer de photo ; appuyez sur la patte pour voir la liste des voies. Les panoramas, cartes et informations d’approche n’apparaissent que si la source les fournit.

Lire un topo et une scène 3D

Touchez une ligne ou un numéro pour afficher nom, cotation et, si elles existent, longueur, points d’assurage et première ascension. Pincez ou double-touchez pour zoomer. Le balayage latéral change de photo sans voie sélectionnée, ou de voie lorsqu’une voie est active. Certains guides disposent d’un modèle 3D ; l’application n’invente pas les données absentes.

Cartes, accès et navigation

Lorsque l’auteur les fournit, vous pouvez ouvrir les cartes des parois, photos de secteur, instructions d’approche et liens vers un service de navigation. Les coordonnées GPS indiquent parfois la falaise ou l’accès, et non le départ précis de la voie. Vérifiez restrictions d’accès, sécurité et météo.

Journal d’escalade

La patte ouvre la liste des voies. Pour chaque voie, la patte alterne « Pas encore », « Réussie », « Grimpée », puis « Pas encore ». Vous pouvez filtrer par statut. Les informations sont conservées localement.

Ranger et fusionner

Maintenez une carte de falaise puis déplacez-la pour modifier l’ordre. Déposez-la sur une autre falaise pour former une collection, que vous pourrez renommer ou séparer. Les sources d’origine restent associées. Supprimer une collection supprime ses données locales : effectuez une sauvegarde. Le menu peut également suggérer des regroupements fondés sur les sources.

Collecter et importer

Collecteur Redpoint Cat

Méthode A : ouvrir un lien de partage Climbio. B : avec l’extension de collecte de Redpoint Cat dans Chrome sur ordinateur, enregistrer des sites compatibles comme theCrag ou OpenClimbing, puis synchroniser le téléphone. C : importer un fichier .climbio ou ZIP. Une collection personnelle n’autorise pas automatiquement la republication des contenus tiers.

Partager

Les guides dont vous possédez les droits peuvent être partagés par lien. Publiez vos propres contenus via Studio ; pour un échange privé, utilisez un fichier ou le partage direct entre amis. Les collections personnelles d’autres sites ne peuvent pas être publiées sans autorisation. Respectez les crédits et licences des textes, photos et topos.

Partager avec des amis

Les deux appareils ouvrent Redpoint Cat sur un Wi-Fi autorisant l’échange direct. Utilisez « + → Envoyer à des amis », choisissez une personne et une falaise ou un topo ; le destinataire confirme la réception. Journaux, préférences et clés ne sont pas envoyés. Recevoir un contenu ne le publie pas dans « Monde ».

Synchroniser mes appareils

Sur vos deux appareils, ouvrez la synchronisation personnelle et validez le même code à quatre chiffres. Falaises, topos, collections personnelles et journaux sont échangés. Chaque nouvelle synchronisation exige que les deux appareils gardent la page ouverte sur un réseau permettant la liaison directe. Pas de synchronisation en arrière-plan, ni des suppressions.

Sauvegarder et changer d’appareil

Depuis les réglages, exportez les falaises sélectionnées au format .climbio, puis importez le fichier sur le nouvel appareil. Vérifiez les photos, topos et journaux avant de supprimer les données de l’ancien. Lisez les avertissements avant de remplacer une collection existante.

Mises à jour, réseau et stockage

Les données téléchargées sont affichées en priorité depuis le stockage local. Certaines sources sont vérifiées lorsqu’une connexion existe. Si des images manquent, téléchargez-les à nouveau en ligne : une fiche texte ne suffit pas pour un topo réellement hors connexion. Photos et modèles 3D occupent de l’espace ; sauvegardez régulièrement.

Questions fréquentes

Si une falaise manque dans « Monde », essayez un lien, la collecte depuis un ordinateur ou un import local. Si les photos sont absentes sur le terrain, complétez le téléchargement et testez en mode avion. Toutes les sources n’ont pas de topo, carte ou 3D. Redpoint Cat consulte les guides ; leur édition se fait dans Studio.

Pour aller plus loin et licences

Studio peut convertir d’anciens guides Word, PDF ou web. Votre site de falaise peut proposer une entrée de données au format Climbio. Conservez les attributions et les autorisations d’OpenStreetMap, de theCrag et des photographes.

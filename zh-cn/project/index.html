使用说明

把 Climbio 放进你的岩馆 App

用你熟悉的 AI Agent，把看线和定线画面放进现有的岩馆 App，无需另外开发。这里说明做法；技术规格和整合步骤统一在 GitHub。

用 AI Agent 整合进你的 App

岩馆人员只要三步：1. 复制下面这段话。2. 贴给你平常用的 AI Agent（Claude、ChatGPT、Codex 都可以）。3. 按它的提问回答，例如墙面照片放在哪里。Agent 会先处理墙面，再整合进 App；之后墙面有更新，也按同一份说明做。需要你决定的它会先问。

请先阅读 https://github.com/climb-io/climbio/blob/main/docs/embed.md 和 https://github.com/climb-io/climbio/blob/main/docs/gym-agent.md，帮我把我们岩馆整合进 Climbio，分三个阶段做：
1. 处理墙面：用 Climbio Studio（https://climbio.app/studio/wall/）把墙面照片整理成岩点档并发布，取得墙 id。若由你操作命令行，执行 node tools/studio.mjs start gym <文件夹> <照片…>，按它打印的下一步做；岩点要自己看图检查到定案，看不准的放大再看。
2. 整合 App：在现有的岩馆 App 放内嵌页（iframe 或 WebView），数据只用官方网址；用户定完路线用 submit 提交，记下返回的 routeId 对应我们自己的用户。
3. 之后的墙面更新：墙面或岩点有调整，就在 Studio 用同一面墙重新发布（会是新版本，旧路线照旧）；如果换了照片，要当成新的一面墙，换新的墙 id，并告诉我 App 要怎么切换。
需要我决定或提供的东西（墙面照片、用户怎么对应路线、要不要固定某一版）请先问我，不要自己编造。每个阶段做完，告诉我怎么验收。

请 AI Agent 先阅读整合说明，三步完成：用 Studio 整理并发布墙面，把看线、定线画面放进 App，再用固定的墙 id 更新路线。适合愿意和岩友分享路线的岩馆；用户与路线如何对应，由你的 App 决定，Climbio 不介入。

整合说明（给 AI Agent）岩馆 Agent 指南

现在能做什么

岩点猫用于定线和分享；红点猫可以下载岩场数据离线阅读；朋友互传、红点猫收藏和 Studio 提供不同的数据整理方式。功能仍在持续改进。

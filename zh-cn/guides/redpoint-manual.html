红点猫使用说明

收藏岩场、离线 Topo、记录、分享与备份。

第一次使用

用手机浏览器打开红点猫，也可以添加到主屏幕。按首页右下角的地球进入“世界”，找到岩场并下载 Guidebook；出发前打开几张 Topo，并使用飞行模式确认离线可读。

安装

红点猫是无需应用商店的网页 App（PWA）。iPhone/iPad 用 Safari 的“分享 → 添加到主屏幕”，Android 用 Chrome 的“安装”功能。

iPhone 浏览器与主屏幕 App 的本地资料可能互不相通；安装后必要时重新下载。LINE 等内置浏览器可以接收分享链接，安装请使用 Safari 或 Chrome。

找岩场

首页右下角“世界”先展示国家卡片，点击后依次展开地区和岩场卡片。选择岩场即可查看并收下 Guidebook。

“世界”包含已发布的 Guidebook 和可用的 OpenClimbing 数据，不保证所有岩场都有 Topo；找不到时可使用分享链接、电脑收藏工具或本地文件。

离线下载

选择岩场下载，等待照片、路线和地图资料完成后打开查看。出发前浏览需要的 Topo，检查是否仍有图片未下载。

只有完整下载的资料才可离线查看；新岩场、世界目录、网上导入及外部导航仍需要网络。

浏览岩场、Topo 与 3D

在首页选择岩场及岩壁，打开照片 Topo；有多张时左右切换。点击路线或编号查看名称、难度，以及来源提供的长度、Bolt、首攀等资料。

捏合或双击缩放；未选路线时左右切换 Topo，已选路线时左右切换路线；右下爪印打开路线列表。部分 Guidebook 提供 3D 模型，没有模型时正常使用照片 Topo；缺少的资料不会自动杜撰。

地图、交通与导航

如果作者提供资料，岩场页会有岩壁地图、区域照片、交通说明或外部导航。地点坐标可能只是岩场或入口，并非起攀点；请结合现场安全、天气与合法进入条件判断。

攀登记录

点击右下爪印打开路线列表；每条路线的爪印状态依次切换“没爬 → 完攀 → 爬了 → 没爬”。可按状态筛选，记录保存在设备中。

整理与合并

在首页长按岩场卡片拖到两张之间可调整顺序，叠放在另一张岩场卡片上可合并为合集；长按放开可分享、删除、重命名或拆开合集。

合并保留原始数据与来源；删除合集会删除设备内的成员资料，未备份可能无法恢复。可在设置中查看依来源关系推荐的自动合并候选。

收藏与导入

红点猫收藏

方法 A：打开别人分享的 Climbio Guidebook 链接。方法 B：在电脑 Chrome 安装“红点猫收藏”扩展，收藏支持的 theCrag、OpenClimbing 或 Climbio 格式网站，再通过“我的设备”与手机同步。方法 C：通过设置导入 .climbio 或 ZIP 文件。

电脑收藏只支持部分网站，手机浏览器没有相同扩展功能。个人收藏不等于获得公开转载权。

分享

有分享权限的 Guidebook 或 Topo 可发送链接。自己有权发布的内容通过 Studio 公开发布，私下传送可用导出文件或朋友互传。

没有重发权限的外部个人收藏不显示公开分享；合集不能整组公开分享。请核对照片、文字和 Topo 的作者及许可。

朋友互传

两台设备在同一个允许直连的 Wi‑Fi 中打开红点猫，通过首页“＋ → 传给朋友”选择附近的人及岩场或 Topo，等待对方“收下”。无需预先配对，也不会自动公开。

个人攀登记录、设置和设备密钥不会传给朋友；外站收藏的内容仍须遵守原授权。连线不可用时才出现二维码备用方式。

朋友互传

我的设备：双向同步

电脑和手机都打开“头像 → 同步到其他设备 → 添加新设备”，核对四位数字并确认。同步岩场、Topo、个人收藏与攀登记录。

配对一次即可，但以后仍需两台同时打开“我的设备”页面、处于可直连的同一个网络；不是后台同步。删除不同步，攀登记录只增不减。两个 App 需分别配对。

备份与换手机

在设置中“导出”并勾选要保存的岩场，产生 .climbio 备份；在新设备“导入”后勾选需要恢复的岩场，覆盖前检查提示。

备份包含所选岩场的照片、Topo 和攀登记录；检查无误前不要清除旧设备。

更新与存储

已下载的资料优先从本地显示。联网打开已收藏岩场时，部分来源会检查更新。图片下载中断后必须补齐，只有文字和路线不算完整离线 Topo。

图片和 3D 可能占用大量空间；清除浏览器数据或卸载 App 会造成资料丢失，请先导出。

常见问题

世界中没有某岩场：尝试分享链接、电脑收藏或本地导入。山上图片无法显示：在有网络时补下载并用飞行模式检查。

看不到 Topo、地图或 3D，是因为来源未提供相应资料。个人收藏没有公开分享按钮是权限限制；需要编辑 Guidebook 时请使用 Studio。

下一步与资料授权

想数字化旧路线书可使用 Studio 转换 Word、PDF 或网页；已有网站可以提供 Climbio 格式入口。开放数据和外部照片的来源、署名与授权必须保留。

岩點貓使用說明

拍下岩牆，自己定線。

開啟岩點貓

第一次使用

  1. 拍照：按「＋」拍照或選相簿照片，裁切到牆面範圍。
  2. 辨識：等系統找出岩點；漏掉的可在定線時長按補上。
  3. 定線：選難度、起攀和完攀，完成後就能看線和分享。

安裝

岩點貓是網頁 App（PWA），手機、平板、電腦都能開，也可以加到主畫面。

iPhone / iPad

用 Safari 開啟岩點貓，按「分享」→「加入主畫面」。

Android

用 Chrome 開啟岩點貓，選「安裝」或「加入主畫面」。

LINE 等內建瀏覽器可能限制選檔、儲存和安裝，請改用 Safari 或 Chrome。

資料主要存在目前裝置的 App／瀏覽器。不同瀏覽器或另一支手機看不到同一份。

新增岩牆

  1. 按首頁的「＋」，拍照或選相簿照片。
  2. 裁切，讓要爬的牆面留在畫面內。
  3. 按完成，等辨識結束。
  4. 確認岩館與牆面名稱，之後也能改。

手機會用照片裡的位置資訊建議附近岩館。沒有位置、沒授權或附近沒有岩館時，自己選即可。

岩點清楚、不過暗、少反光的照片辨識最準。很寬的牆可用 Studio 處理多張照片。

自動辨識

岩點貓分析裁切後的照片，用輪廓標出岩點，完成後直接進入定線。

  • 大型 Volume、陰影、遮擋處可能漏掉或辨錯，可手動修正。
  • 先顯示初步結果，精細輪廓可能還要載入模型或連網。
  • 失敗時依提示重試，不必重拍。

首次載入模型、精細輪廓和分享需要網路。

修正岩點

在定線畫面長按岩點：長按已辨識的岩點可編輯，長按漏掉的位置可補一顆。

  1. 長按要修的岩點，畫面放大到附近。
  2. 讓系統重描輪廓，或直接拖曳外框的控制點。
  3. 用浮動工具確認、復原或刪除。

岩點靠近或重疊時先放大再選。外框還在背景處理時，編輯會暫時受限。

定線

  1. 在牆面頁按「＋」，或點牆面照片。
  2. 選難度，下方切換類型：起攀、手點、完攀、腳點。
  3. 點照片上的岩點加入路線；再點可改類型或移除。
  4. 至少要有起攀和完攀才能完成，名稱可以之後補。

起攀最多兩顆。要註記出手順序，切到「順序」依動作點選；同一顆岩點可在不同步驟重複使用。

要改自己的路線，從牆面卡片或看線畫面進入編輯。別人分享、不可直接改的路線，可建立自己的版本。

看線

在牆面頁點一條路線，進入全螢幕路線圖。

操作用途
左右滑動前一條／下一條路線（照片放大時優先移動照片）
雙指縮放放大看密集岩點，放大後可平移
點兩下照片放大點選位置，再點兩下還原
灰階／暗彩降低背景干擾
往下滑或左上返回回到牆面與路線清單
鉛筆圖示編輯路線

資料有提供跨照片關聯時，才會出現跨照片切換。

完攀紀錄

看線時按右下完攀鈕記為完攀，再按取消。只有「完成／未完成」，沒有嘗試次數、日期或 Flash。

牆面清單可依完攀／未完攀篩選，並依難度或時間排序。紀錄存在這台裝置。換裝置時可用備份復原或「我的裝置」。

分享

完成路線後可分享路線圖或連結。圖片方便在群組討論；要讓對方收到可操作的牆面與路線，用 App 提供的分享／發佈方式。

  • 收到朋友的連結：先確認來源與內容，再加入自己的裝置。
  • 公開分享：連結可讓朋友查看可操作的路線，公開牆面也會出現在找牆面的清單。
  • 朋友互傳：首頁「＋」選擇「傳給朋友」，挑選附近的人與要傳的牆面，對方確認後收下。

分享牆面不會公開整支手機的資料。公開前確認照片作者、岩館同意與隱私。

朋友互傳

  1. 兩台裝置連上同一個可互相連線的 Wi-Fi，開啟岩點貓，首頁按「＋」→「傳給朋友」。
  2. 選擇「附近的人」及要傳的牆面，可一次選擇多位朋友，按「傳給 N 人」。
  3. 對方看見收到邀請後按「收下」，牆面照片、岩點與路線就會傳到對方裝置；也可以按「不要」。

不必事先配對。朋友收到的是本機資料，不會因此公開；你的完攀紀錄、個人設定及裝置金鑰不會傳給朋友。朋友互傳完整介紹

找不到對方時，確認兩台在同一個 Wi-Fi；部分訪客網路會禁止裝置直連。只有連線服務未設定或無法連上時，才會出現 QR code 備援，依畫面提示互相掃描。QR code 不用於一般找人。

我的裝置（雙向同步）

  1. 兩台裝置都開啟「頭像 → 同步到其他裝置 → 加入新裝置」。
  2. 在附近裝置清單選對方，確認兩台顯示相同的四位數，各自按「一樣，確認」。
  3. 配對完成後會自動同步缺少或較新的牆面、路線和完攀紀錄，頁面會顯示「同步中」與「已同步」。不必再選牆面或按傳送。

之後不必重新配對，但兩台都需要在可以直接連線的同一網路，同時開啟「我的裝置」頁面才會同步；不會在背景或只靠登入自動同步。取消配對可從這個頁面操作。

自己的裝置會交換完攀紀錄及路線編輯權限所需的資料；3D 牆只同步路線，模型需各自下載。刪除不會同步，攀登紀錄只增不減。無法同網路連線時，改用下方的備份／復原；岩點貓和紅點貓要各自配對。

找牆面

首頁「＋」選單若有「找牆面」，可瀏覽公開的岩館與牆面，選牆下載後會出現在首頁。清單只含有公開資料的牆，下載需要網路。

備份與換手機

牆面、路線、岩點修改和完攀紀錄主要存在這台裝置。換手機前先備份，再於新裝置復原。

  1. 原裝置的選單按「備份資料」，儲存 .climbio 備份檔。
  2. 把檔案帶到新裝置，開啟岩點貓並按「復原資料」，選取備份檔。
  3. 確認照片、路線和完攀都正確，再清除舊裝置。

一般分頁與主畫面安裝版可能用不同儲存區。沒備份前不要清除網站資料。

離線與更新

  • 可離線：已儲存的照片與路線。
  • 需網路：首次載入模型、精細輪廓、公開分享及收下公開牆面。
  • 更新：連網時會取得新版，更新前先備份。

下載或存檔失敗時，先檢查網路、權限與裝置空間。

3D 與實驗功能

主要流程以 2D 照片為主，不必等 3D。3D 重建與辨識研究在 Climbio Lab；大量照片整理與正式發佈用 Studio；要拍 3D 用的岩壁照片，見如何拍 3D 照片。

常見問題

沒有找出所有岩點

先確認裁切與清晰度；進入定線後長按漏掉的位置補點，或長按辨識錯的岩點修輪廓。

為什麼要下載模型？

辨識與輪廓修正可能用不同模型，第一次使用或模型更新時需要載入，部分精細功能還要連網。

只有照片、沒路線可以存嗎？

可以。牆面先存在裝置，之後再定線；辨識失敗也不必重拍。

如何修改自己的路線？

從牆面路線卡片或看線畫面的鉛筆圖示進入編輯；要調岩點，在定線畫面長按。

換手機後看不到原本的牆

資料以本機為主。兩台可同時開啟「我的裝置」並直連時可配對同步；否則先在舊裝置備份，再到新裝置復原。確認資料完整前不要清除舊裝置。

找不到附近岩館或公開牆面

岩館建議受位置與授權影響，公開清單也不含所有岩館。可手動選岩館，或直接拍照建立自己的牆面。

想整理大量照片、拼接牆面或做 3D

大量編輯用 Studio；3D 與辨識研究見 Lab。

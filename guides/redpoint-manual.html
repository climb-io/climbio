紅點貓使用說明

想爬哪裡，就帶哪裡。紅點貓是 Guidebook 閱讀器；編輯與製作路線書請用 Studio。

開啟紅點貓

第一次使用

  1. 開啟：用手機瀏覽器開啟紅點貓，也可以加到主畫面。
  2. 收下：按右下角地球「世界」，在地圖上找到岩場並下載 Guidebook。
  3. 確認：打開岩場與 Topo，確認圖片都已下載；出發前可用飛航模式檢查。

安裝

紅點貓是網頁 App（PWA），不用商店。第一次成功收下岩場後，首頁會出現一次可關閉的「加到主畫面」提示。常去岩場、需要長期離線的人，建議安裝後再下載。

iPhone / iPad

用 Safari 開啟紅點貓，按「分享」→「加入主畫面」。

Android

用 Chrome 開啟紅點貓，按「安裝」或「加入主畫面」。

LINE、Messenger、Instagram 的連結可直接在原瀏覽器收下；要加入主畫面才需改用 Safari／Chrome。

iPhone 的瀏覽器與主畫面 App 本機資料各自獨立，新安裝的主畫面 App 可能要重新下載岩場。

下載好的岩場、Topo 與攀爬紀錄都能離線查看；取得新資料與公開分享需要網路。

找岩場

  1. 在首頁按右下角地球「世界」。
  2. 世界先看到一疊一疊的國家卡片，位置大致照地理排列，厚度代表岩場多寡。
  3. 點一疊展開成地區，再點一疊攤開成岩場卡片；左上角返回會收回上一層。
  4. 選岩場，查看可下載的 Guidebook 後收下。

世界包含作者透過 Climbio 發佈的 Guidebook 與可用的 OpenClimbing 資料，不是所有岩場的完整名錄，也不是每個點都有 Topo。找不到時，改用朋友的分享連結、收藏工具或本機資料包匯入。

離線下載

  1. 在「世界」選一個岩場按下載／收下，或直接開別人傳來的 Guidebook 連結。
  2. 等照片、路線與地圖資料下載完成。
  3. 按「看這個岩場」，岩場也會出現在首頁。
  4. 出發前開幾張 Topo，確認沒有「照片還沒下載」的提醒。

資料存在目前裝置的瀏覽器／App 儲存空間，沒網路時仍能看已完整下載的岩場、Topo 與個人紀錄。

第一次開「世界」、取得新岩場、從網路匯入與外部導航都需要網路。下載中斷時，連線後依提示補齊照片。

瀏覽岩場

  1. 在首頁點岩場卡片，進入岩場頁（入口照片與各岩壁小卡）。
  2. 點岩壁小卡，打開第一張 Topo。
  3. 有多張 Topo 時左右切換，也可從岩場頁選別的岩壁。
  4. 右下爪印開啟路線清單。

資料依來源而異；有交通、原始資料或區域圖時，入口照片旁才有對應按鈕。

Topo 與 3D

Topo 是疊在岩壁照片上的路線圖，依資料顯示線條、編號與難度。

操作效果
點路線或編號凸顯路線，顯示名稱、難度、長度、Bolt、首攀與說明（來源有提供的欄位）
再點同一條／照片空白處收起路線資訊
雙指縮放、點兩下放大看細節，放大後可拖曳
未選路線時左右滑前一張／下一張 Topo
已選路線時左右滑上一條／下一條路線
未放大時往下滑返回岩場頁
電腦滑鼠或鍵盤滾輪縮放、左右方向鍵換張、Esc 返回

缺少的資訊（Bolt、確保站等）不會憑空補上。

3D 岩壁

部分 Guidebook 附 3D 模型，開啟模型照片即可用手勢轉視角。沒有模型的岩場照常看照片 Topo。

地圖、交通與導航

只有資料提供時，岩場頁才有這些入口。

  • 岩場地圖：看岩壁、石頭、分區與步道，可點進對應 Topo。
  • 區域照片／配置圖：以照片看岩壁分布。
  • 交通說明：作者提供的停車、入口、步道資訊。
  • 導航：有座標時，可開外部地圖 App 前往。

地圖位置只是岩場或入口的參考點，不一定是起攀點，不能代替現場判斷、合法進入資訊與天候判斷。外部地圖是否離線可用取決於該 App。

攀爬紀錄

  1. 在岩場頁按右下爪印，開啟路線清單（依岩壁整理）。
  2. 點一條路線，跳回它的 Topo 並凸顯。
  3. 點路線右側的爪印狀態，依序切換沒爬 → 完攀 → 爬了 → 沒爬。
  4. 清單上方可依完攀／爬了／沒爬篩選；再點目前條件取消。

紀錄存在這台裝置；換手機前請先備份，或使用「我的裝置」。

整理與合併岩場

在首頁長按卡片，浮起後拖曳：

  • 放在兩張卡片之間：調整順序。
  • 疊在另一張岩場卡片上：合併成合集（Topo 單張卡片不能合併）。
  • 長按後放開：出現分享、刪除等動作；合集可重新命名或拆開。

合併後原始資料、來源與個人紀錄仍保留，可再拆開。設定裡若有「自動合併岩場」，會依來源關係列出候選供你確認。

刪除會移除這個裝置內的岩場與照片，刪除合集會連成員一起刪，沒備份可能無法復原。本機刪除不會影響外站來源或你另存的備份檔。

收藏與匯入

方法 A：分享連結

點開朋友傳來的紅點貓／Climbio Guidebook 連結並收下。已收過的會直接開本機版本；能否使用取決於原資料的權限與連線。

方法 B：電腦 Chrome 收藏外站

  1. 在電腦 Chrome 安裝紅點貓收藏工具。
  2. 前往支援的網站（有 Topo 的 theCrag、OpenClimbing，或提供 Climbio 格式的網站），打開岩場頁後按收藏工具。
  3. 擴充會自動打開電腦上的紅點貓分頁，把岩場收進去。
  4. 電腦和手機連上可互相連線的同一個 Wi-Fi，兩邊都開紅點貓的頭像 → 同步到其他裝置，核對四位數配對。之後兩台同時開啟「我的裝置」頁面，就會自動交換個人收藏和攀登紀錄；「世界」右上角的附近交換則是傳給別人，不會傳送個人收藏。

這是電腦端流程，只支援部分網站，也不保證每條路線都有 Topo；手機瀏覽器沒有同樣的收藏功能。

方法 C：本機檔案

設定 → 匯入 → 本機檔案，選支援的 .climbio 或 ZIP 資料包。檔案含多個岩場時，只選要的即可。

個人收藏不是公開指南。外站資料受原授權限制，通常只供自己離線閱讀，不會出現在「世界」，也不能直接對外分享。

分享

在有分享權限的岩場或 Topo 上按分享按鈕傳連結，對方點開即可收進自己的紅點貓。

  • 收到的公開 Guidebook：可轉傳原連結；分享特定 Topo，對方收下後會直接看到那張照片。
  • 自己製作且有權發佈的內容：尚未上線時，用 Climbio Studio 發佈（發佈就是公開）；要私下給人用匯出檔或附近交換。
  • 外站個人收藏：沒有分享權限，不顯示分享動作。
  • 合集：不能整組分享，改從有權分享的成員或 Topo 分享。

分享連結僅用於來源允許轉傳的資料；只想傳給現場朋友，可使用附近交換。公開前確認文字、Topo、照片與各作者的授權。

傳給別人（附近交換）

  1. 和朋友連上同一個可互相連線的 Wi-Fi，兩邊開啟紅點貓，在「世界」右上角按附近交換圖示。
  2. 選擇附近的人及要傳的岩場或 Topo，可一次傳給多人。
  3. 朋友按「收下」後，資料會直接存進對方裝置；不需要先配對。

只會列出允許分享的內容，個人收藏與攀登紀錄不會傳給朋友。收下的資料可以在這台離線查看，不會因此公開到「世界」。

兩台裝置需要能直接連線；訪客 Wi-Fi 可能禁止。連線服務未設定或無法連上時，才會顯示 QR code 備援，依畫面互掃連線。

我的裝置（雙向同步）

  1. 電腦、手機或平板都開啟「頭像 → 同步到其他裝置 → 加入新裝置」。
  2. 選擇要配對的裝置，核對雙方的四位數，各自按「一樣，確認」。
  3. 配對後自動交換缺少或較新的岩場、Topo、個人收藏與攀登紀錄，畫面顯示同步進度及結果。

配對只需一次；以後兩台同時打開「我的裝置」頁面，並處在可互相連線的同一網路，就會再次自動同步。不需要逐項點選，也不會只因開啟 App 就在背景同步。

刪除不會同步，攀登紀錄只增不減。無法直接連線時，用下方的匯出／匯入備份；與岩點貓使用同一個暱稱，但各 App 必須分開配對。

備份與換手機

岩場、照片、Topo 與攀爬紀錄主要在這台裝置。旅行前或換手機前，請先匯出保存。

匯出

設定 → 匯出 → 勾選岩場 → 儲存備份檔。含所選岩場的照片、Topo 與攀爬紀錄。

匯入

設定 → 匯入 → 選備份檔 → 勾選要還原的岩場。已有同一筆資料時先看覆蓋提醒。

匯出會產生 .climbio 備份檔；匯入只處理勾選的岩場。要在自己的裝置間交換資料，也可使用「我的裝置」。

換手機順序：舊手機匯出、確認完成、新手機安裝紅點貓並匯入、檢查照片與紀錄。成功復原前不要清除舊裝置。

更新、網路與儲存

  • 已下載優先：開 App 先顯示本機資料，不必等網路。
  • 新版檢查：連網開啟已收下的岩場時，來源有新版會更新；不是每種匯入來源都支援。
  • 訊號中斷：提示有照片未下載時，有網路再補下載。只有文字／路線、沒有照片，不算完整離線 Topo。
  • 手機容量：照片與大型資料包佔空間。清除網站資料、換瀏覽器或移除 App 可能讓本機資料消失，重要紀錄先匯出。
  • 戶外：出發前先開過所需岩壁、確認來源與導航資訊；地圖不是安全保證。

常見問題

在「世界」找不到想去的岩場

世界只含目前可取得的資料。試試移動或縮放地圖，或用分享連結、收藏工具或本機資料包匯入。

照片在山上顯示不出來

可能是下載未完成、部分照片來源失敗，或在另一個瀏覽器環境下載。回到有網路處，在同一個紅點貓 App 內依提示補下載，再用飛航模式檢查。

手機可以直接收藏 theCrag 嗎？

目前以電腦 Chrome 收藏工具為主：在電腦收進紅點貓，再用「頭像 → 同步到其他裝置」配對，傳到手機。

為什麼某個岩場沒有 Topo 線、地圖或 3D？

紅點貓只顯示來源提供的資料：有些岩場只有路線清單，有些照片沒附線條；3D、地圖與導航也要有模型或位置資料。

另一支手機沒有同一批岩場

兩台都需在同一個可直連網路開啟「我的裝置」才能同步；無法直連時，請匯出／匯入備份，或重新收下原分享連結。

為什麼個人收藏沒有分享按鈕？

收藏只表示可供自己閱讀，不代表有重新公開的授權。見資料來源與授權，必要時聯絡作者。

可以在紅點貓改路線或畫 Topo 嗎？

不行。要製作或修改 Guidebook 請用 Studio；已有路線書可看轉換路線書教學。

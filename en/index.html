Red Dot Cat ↗ User guide

Where does crag data come from?

Red Dot Cat's crag data is compiled by climbers and authors. If a crag is already there, collect it from World; if not, there are three ways to bring it in.

Simplest: pick a crag in Red Dot Cat World and download it to read the topo offline.World

Collect a crag

Collect a crag from a supported site on your computer, then pair Red Dot Cat with your phone under Sync to other devices. Both devices must be on the same network.

Convert a guidebook

Already have a guidebook in Google Docs or Word? No need to redo it: convert it into a Guidebook with tappable routes on the phone.

Connect a crag website

Crag data on your own website? Expose an entry point in the open format and Red Dot Cat can read it, offline too.

Studio: the tool for preparing data

For guidebook authors and crag maintainers: no need to redo an existing guidebook. The tools do the first pass; you only review what needs a second look.

  1. Guidebook and photosWord, web pages, PDF, the author's originals
  2. OutlineAreas, walls, routes and photos read out
  3. TopoRed lines on the photos traced automatically
  4. Red Dot CatClimbers download it and read it offline

Natural crags

Organize cliffs, routes and topos into a Guidebook that Red Dot Cat can read offline; existing guidebooks can be converted directly.

Indoor walls · Lab

Refine hold outlines and explore 3D walls. These are research tools, not the regular Studio publishing flow.

Developers

One set of data, readable by people and by AI

The route Hold Cat draws is a file in a public format. Websites, apps and AI agents can all read it, and check, convert and improve it with the same tools.

  • Open format

    Specification, schema and validator under Apache-2.0, so any app can implement it.

  • Standalone kits

    Route views, topos, maps and hold detection you can use on their own in your site or app, under AGPL-3.0.

  • Command line for AI agents

    Read a guidebook, check it, build a Guidebook and make targeted fixes without opening the app; every step produces the same issue list.

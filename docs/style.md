# 介面風格

新增或修改介面前先照這份做，做完用下面的「檢查清單」對一次；這份跟實際畫面不一樣時，先改這份再改程式。各畫面的細節在 [app.md](app.md)、[sharing.md](sharing.md)，樣式在 `css/app.css`。

## 1. 方向

- **輕盈、時尚、好玩，但不搶戲**：路線的主角是岩點，標示、按鈕、文字都是配角。好玩靠手感和小特效（按下彈一下、小人、膠帶），不靠花俏的顏色和裝飾。
- **手機、平板與電腦皆可操作**：手機維持直式、單手；寬視窗沿用多欄卡片與限寬內容，滑鼠可直接選照片、定線和看線。介面同時檢視手機與電腦寬度。桌機共用 `css/desktop.css`：一般內容最寬 1200px、兩側 24px、卡片間距 16px；照片與地圖工作區使用完整視窗；定線工具最寬 640px 並置中，對話框最寬 480px 並置中。
- **功能越少越好**：能用版面表達的不加按鈕，能自動做的不讓人選（例如打開 App 時自動換新版）。
- **固定深色**：不提供淺色外觀。

## 2. 顏色

只用介面變數（`--bg`、`--surface`、`--text`、`--muted`、`--accent`…：`appkit/ui.css` 從 `css/brand-tokens.css` 的室內主題對過來），不在元件裡另寫顏色（圖上的標示色除外）。

| 變數 | 用途 |
|---|---|
| `--bg` `#0e0e0f` | 頁面底色 |
| `--surface` `#161618`／`--surface-2` `#1e1e21` | 卡片、對話框／一般按鈕、輸入框、選單 |
| `--line`／`--line-strong` | 細框線、分隔線（能不用就不用） |
| `--text`／`--muted` | 內文／次要文字、說明、小字 |
| `--accent` `#d4ff4f`（螢光萊姆綠） | **只當點綴**：主要動作、選中狀態、進度、小人 |
| `--danger` `#ff4d4d` | 刪除、登出、還沒同步的警告 |
| 起攀 `--start`、手點 `--hand`、腳點 `--foot`、完攀 `--top` | 路線類型，只用在岩點與標籤 |
| 膠帶 `#f3eee2` 底、`#1f1c18` 字 | 膠帶標籤（見 4.4） |

- 一個畫面最多一個螢光綠的主要動作。
- 選中：螢光綠底配 `--on-accent` 的字，或螢光綠外圈（小圓鈕）。

## 3. 字

| 用途 | 字型 |
|---|---|
| 介面 | `--font`（系統字：SF Pro、PingFang TC、Noto Sans TC） |
| 難度、數字（V5、2/2、人數） | `--display`：Barlow Condensed 窄體斜字（`fonts/`，離線可用） |
| 段級（日本的難度） | `.dan`：M PLUS 1 Black，正體、小一號 |
| 膠帶標籤 | 中文、日文 Huninn（jf open 粉圓），英文 Permanent Marker；用 `capFont()` 取得，背景載入，載好前用介面字 |

- 字重偏細：內文 400–600，標題、按鈕 600–700，大字 800。
- 大標題一句話，不加句號；說明一句一行，長句用 `text-wrap: balance` 避免最後一行只剩一兩個字。

## 4. 元件

元件只有下面這幾種，新的畫面從這裡挑，不另外發明。

### 4.1 按鈕

| 元件 | 樣子 | 用在 |
|---|---|---|
| `.btn.primary` | 螢光綠膠囊 | 每個畫面唯一的主要動作；要按的放在拇指範圍（畫面下方），整條寬（最寬 420px）、高 48–54px |
| `.btn` | 灰底膠囊 | 次要動作（取消、再看一次） |
| `.btn.danger-fill` | 紅底膠囊 | 刪除、登出這類收不回的確認 |
| `.vw-btn` | 深色半透明圓鈕（`rgba(14,14,15,.55)`，上方工具 `.35`，不模糊） | **浮在照片上**的按鈕（路線圖、定線的返回、取消、完成） |
| `.log-mark` | 深色半透明圓角標記（`rgba(14,14,15,.65)`，不模糊） | 清單裡每張卡片都有的照片上標記（路線小卡左上的紀錄標記）：一頁幾十顆；卡片的選單用長按打開，照片上不放按鈕 |
| `.vw-btn.ed-ok` | 螢光綠圓鈕＋✓ | 照片上的「完成」 |
| `.icon-btn`、只有圖示 | 沒有底，按下才出現灰圓 | **一般深色底**上的返回、關閉（分享畫面的 ×） |
| `.sh-app` | 大圓鈕＋下面一行名稱 | 分享目標（圖片、連結） |

- 圓底只用在需要跟照片隔開的地方；一般深色底上的返回、關閉不加圓底。
- 左上一律是返回 `<`（離開這一步是 ×），跟其他頁面同一個位置、同一種樣子。
- 按下去縮一下（`scale: .94`）、放開彈回來（`--spring`）。**按下縮放一律用 `scale` 屬性，不寫 `transform: scale()`**：全域的 `button:active` 會套到每一顆鈕，元素自己用 `transform` 定位（`translate(-50%)` 置中、地圖圖釘）時，`:active` 改 `transform` 會把定位蓋掉，按下就跳位，滑鼠在跳開的那一半時放開不在按鈕上、點擊不算。不要在個別按鈕補 `:active { transform: translate(…) scale(…) }`。`node tools/check.mjs` 會擋。
- 按了要等的（更新、上傳、同步）：按鈕本身或 toast 轉圈，不另外跳對話框。

### 4.2 圖示

- 24×24 的線條圖示，`stroke-linecap/linejoin: round`；同一排的圖示在螢幕上的線條一樣粗（約 2.2px），看起來一樣大（寬的圖示小一號）。
- 看路線圖和定線上方那一排是同一套：圓鈕 46（窄手機 42）、間距 10（窄手機 6）、離上緣 12，位置一一對應（返回＝取消、灰階／暗彩、編輯＝顯示所有岩點、分享＝完成），標題對齊難度轉盤；兩頁切換時工具不位移，改一邊就要改另一邊。
- 圖示在 `hold/index.html` 開頭的 `<symbol>`，用 `<use href="#i-…">`。

### 4.3 卡片、對話框、通知

| 元件 | 樣子 | 用在 |
|---|---|---|
| 卡片 | `--surface` 底、圓角 `--radius`（20px）、細框 | 繼續爬、新版通知 |
| 對話框（`AppKit.ui`，`.ak-dialog`） | 置中卡片、背後壓暗 | 要使用者決定的事（登出、刪除）；不用瀏覽器的 confirm／alert／prompt，一律用 `askConfirm`、`showAlert`、`askText`（`AppKit.ui` 的 `confirm`、`alert`、`prompt`） |
| 從下方跳出的選單 | 底部卡片 | 語言、岩館、攀爬紀錄 |
| 長時間工作的過場 | 佔滿整個畫面：轉圈或主角的圖、標題（在做什麼、對哪一個）、進度條、「下載 3/40」這種數字；做完才關，中間不能操作（Esc 關不掉，關分頁先問） | 會等超過幾秒的下載、上傳、轉換、發佈（Studio 用 `StudioShell.busy`，Crag 的發佈是照片一張張飛走的版本）；不用頁首的小圖示或 toast 代替 |
| toast（`AppKit.ui.toast`） | 下方一顆膠囊，幾秒淡掉 | 做完的回報（已刪除＋復原、已更新到最新版、連結已複製） |
| 內嵌通知 | 內容最上面一條卡片，從上面滑下來 | 不急、但要讓人知道的事（有新版本）；不浮在畫面上、不蓋住標題列 |
| 毛玻璃泡泡 | `--surface` 72%＋模糊 20px | 操作示範的說明、收線的確認卡 |

**浮在照片上的控制不用毛玻璃（`backdrop-filter`），只用半透明深色底**：圓鈕、類型列、單點編輯的膠囊、橫幅的分享鈕都是。照片縮放、拖曳、轉場時，模糊每格都要重讀後面的畫面再算一次，手機會掉格、圓鈕還會閃；清單裡重複很多次的小元件也一樣。透明度不夠看不清就把底加深，不加回模糊。毛玻璃只留給後面不動的大卡片（毛玻璃泡泡、收線確認卡）和頁面上方固定的標題列。

### 4.4 膠帶標籤

米白色膠帶（`#f3eee2` 底、深色手寫字、轉 −3°、帶陰影），跟分享圖上起攀、完攀的標籤同一套。用在：收線的揭曉、操作示範說明卡的標題、登入和登出的標題（`.tape-title`，用 `tapeTitle()` 設定文字和字型）。一個畫面最多一條。

### 4.5 岩點貓

兩種：照片裡的岩點變成貓（新增牆面、完攀，見 [holdcat.md](holdcat.md)）；說明卡上的果凍岩點貓（`#stCard .st-mascot`，別的畫面用 `playMascot(slot, kind)` 複製一份），造型與動作見 [mascot-motion.md](mascot-motion.md)。

- `in`：無耳無臉岩點彈起、長出耳朵和臉，用在開始一件事（登入等開始畫面）。`out`：收耳收臉回到岩點，停 400ms 再結束。
- 跟一兩行字一起出現，像說明卡：小人在上、膠帶標題、置中的短字、按鈕在下。
- 找牆面頁上方的小人（`.find-mini`）：跟著「N 間岩館有公開的牆面」輕輕晃，不放說明卡的進場動畫。
- 分享說明的小人只做開場變身。
- 操作示範：貓與說明固定在左下，解說記錄攀爬時先移到上方，避開右下展開選單。
- 系統設定「減少動態效果」時不播放小人動畫；導引中的岩點貓保持靜止。

## 5. 版面

- 手機寬度，左右留 16px（分享畫面 12px），上下讓開 `--safe-t`、`--safe-b`。
- **主角盡量大**：照片、路線圖、分享預覽佔滿能用的空間；看路線圖照片滿版，控制浮在照片上。
- **有字的內容上不疊按鈕**：分享預覽的卡片上下都有字，按鈕放在預覽外面；照片上的按鈕要有圓底。
- **上方不擠**：上面只放返回／關閉和必要的一兩顆，主要動作放下方拇指範圍。
- **一排一排由短到長**：上面的比下面的短。
- **能由目標決定的不讓人選**：分享的尺寸、風格由分享目標和路線決定；要準備的（產圖）先做好，按下就送出。
- **不打斷正在做的事**：通知、新版只在首頁出現；看線、定線、分享時不跳出來。

## 6. 動態

- 進場：`item-in`（往上 10px 淡入）；彈出：`--spring`。
- 按下的選項當下就亮，重的事（產圖、錄影）晚一格再做。
- 換內容時舊的淡下來輕輕呼吸、新的彈出來（只動透明度和位移，手機忙的時候也不停格）。
- 特效短（1–3 秒）、有意義；新增牆面、完攀由照片裡的岩點長出耳朵和臉來演（[岩點貓](holdcat.md)），不使用全螢幕暗遮罩或巨大獎勵文字；系統「減少動態效果」時不演。

## 7. 文字

- 所有語言包（zh、en、ja、fr、ko、es、de）一起改；日文用攀岩用語（課題、ホールド、グレード）。
- 簡潔、書面；按鈕用動詞（「分享」「登入」「下一步」）。
- **不用 emoji 和裝飾符號**：按鈕、標題、標籤、toast 不放 ✨📁✅🧹★✕ 這類字元；需要圖示用第 4.2 節的線條 SVG，狀態用文字（「保留」「移除」）或顏色。箭頭、關閉、前後頁一樣用 SVG，不用 ‹ › ✕ ←。
- **長度**：按鈕 2–6 個字；對話框標題 2–6 個字；toast 一句、不超過約 20 字，只說結果（「已精簡：保留 4 張，移除 6 張」）。對話框不放說明段落，要說明的放進該步驟的第一次操作示範。
- **不用 `title` 補說明**：不為了解釋功能加 tooltip（手機沒有 hover）；圖示按鈕用 `aria-label` 命名即可。`title` 只留給被截斷的內容（檔名、岩壁名）。
- **不寫「怎麼用」和「為什麼」**：「點一下切換」「系統已分析…」「供 3D 重建」這類句子不放畫面上；計數、狀態、錯誤原因才放。
- **不放用過一次就懂的說明**：不寫「按某某就會怎樣」，用版面、圖示、按鈕表達；真的要教的放進第一次的操作示範。只留做決定需要的內容（分享前的同意、刪除的後果、錯誤原因）。
- 說明卡、登入、登出的口吻像朋友，一兩句就好。
- **先判斷需不需要文字**：可見字串僅用於標題／名稱、動作、即時狀態／結果，以及決策必要的條件或風險；不能歸類就不顯示。空狀態只交代目前狀態與必要下一步，不寫「打開某某就會出現在這裡」等流程教學。
- **資訊不重複**：已有「我的裝置」頁面標題，不再將「這台」當使用者裝置的名稱或補一句「自己的手機」；名稱應比標籤明顯。已可用按鈕表達的動作不再加一段操作說明；配對、同步等必要條件最多用一句短提示，且只放在真正需要的狀態。
- **頭像選單共用底部**：岩點貓與紅點貓都使用 `AppKit.account.footer()` 產生條款、隱私、版本；有來源資訊的 App 額外提供來源連結，不能再在個別 HTML 維護另一套。選單中「使用說明」一律開啟該 App 的正式說明頁，不重新播放示範導覽；底部不再重複放「完整使用說明」。
- **跨 App 暱稱只有一份**：使用者只填一次「暱稱」；岩點貓的簽名、紅點貓的分享作者及配對裝置名稱不可再各做一套輸入或設定。分享、備份沒有暱稱先用共用對話框詢問，不能留空；「我的裝置」自動顯示「暱稱＋裝置類型」，不提供另一顆改名按鈕。未配對時絕不透露暱稱（僅顯示四位匿名代號）。
- **附近交換雷達對齊**：中心只顯示正式貓 Logo，未配對者僅透過發現訊息看到「岩點貓／紅點貓＋四位匿名代號」，真實裝置名稱只能在確認配對後交換。周圍裝置以圓形頭像中心定位；名稱與傳送狀態放在下方，不能改變頭像定位；空狀態及加入裝置畫面也不顯示中心名稱。
- **狀態優先於常駐解釋**：「我的裝置」已逐台顯示「同步中／已同步／離線」，列表下方不得再顯示「同一網路下，兩台開啟此頁時自動同步」等泛用說明；網路條件留給首次配對及連線失敗時的指引。
- **跨 App 共用元件一致**：改名、輸入、確認一律使用共用對話框；其輸入框字級至少 16px（避免手機輸入放大）、圓角、背景、邊框與焦點樣式在 `appkit/ui.css` 直接定義，不得依賴特定 App 的 `.field`。任何共用 UI 更動都要看岩點貓和紅點貓的實際畫面。

## 8. 檢查清單

改完介面先對一次：

1. 手機寬度（例如 412×915）實際操作並截圖，跟改前比。
2. 一個畫面只有一個螢光綠主要動作，而且在拇指範圍。
3. 按鈕沒有疊在有字的內容上；上方沒有擠滿按鈕。
4. 返回、關閉在左上，樣子跟其他頁面一樣；同一排圖示一樣粗、一樣大、對齊。
5. 顏色、圓角、字都用第 2–3 節的變數和字型。
6. 每條可見文案都有必要用途（名稱／動作／狀態／決策條件），沒有重複標籤、教學語氣和多餘的「這台」；空狀態沒有操作長文。沒有 emoji、說明性 `title` 或對話框說明段落；七個語言都有且排得下（`tools/textfit.js`）。
7. 共用對話框在岩點貓、紅點貓都實際開啟確認，輸入字至少 16px、欄位沒有瀏覽器預設黑框，且符合各自品牌色。
8. 等待有回饋（轉圈、進度），而且不會一直等下去；長時間的下載、上傳、轉換有全螢幕過場（第 4.3 節），每個產品都一樣；打不開、失敗要說原因，不停在空白畫面。
9. 「減少動態效果」時動畫關掉、畫面照樣看得懂。
10. 按下有縮放的按鈕，按住時位置不變（用 `transform` 置中、定位的元素尤其要按住看一次）。

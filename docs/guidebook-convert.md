# 做過的路線書，不用再做一次

> 紅點貓資料藍圖的作者／維護者入口。三條推廣路徑與首頁設計見 [紅點貓資料藍圖](redpoint-data-blueprint.md)。

**已經花很多時間整理好的岩壁、路線和照片，不需要為了數位化再做一次。**

你手上可能有一份 Google 文件、Word，或多年整理下來的岩場路線書。裡面有路線名稱、難度、照片、交通方式，以及只有熟悉這個岩場的人才知道的資訊。

**Climbio Studio 幫你把現有資料轉成可以繼續編輯、分享與更新的數位 Guidebook。** 先讓工具整理，再由你確認重要的部分；不用逐條重新輸入，也不用先學資料格式。

**[開啟 Climbio Studio，試著轉換一份路線書](https://climbio.app/studio/)**　·　**[完整教學：怎麼轉、哪裡要你看一眼](https://climbio.app/studio/convert/)**

轉換的底線是**每張 Topo 上的每條路線，在紅點貓裡都有東西可以點**：照片上畫好的紅線自動描出來；編號不對或少了可以在 Topo 上改；描不出線的路線先放一個記號，你再拖到位置或自己重畫。天然岩場一定要有岩場位置（文字裡的座標會自動抓，沒有就貼上），沒有位置不能發佈。區域圖能轉成 GeoJSON 就轉，不行就直接用原圖。作者原始、沒畫線的照片是轉完之後的選用優化。

## 你原本整理的資料，可以繼續用

匯入路線書後，Studio 會嘗試自動完成這些工作：

- **整理岩場架構**：辨認區域、岩壁、石頭與路線的層級。
- **保留路線資料**：匯入名稱、難度、類型、Bolt 數、長度、首攀與說明等資料。
- **整理照片**：將照片放到對應岩壁，保留圖說。
- **製作可編輯的 Topo**：嘗試把照片上原本畫好的紅色路線描成數位線條。

轉換時會先顯示預覽：找到幾個區、幾面岩壁、幾條路線、幾張照片，以及哪些地方需要確認。**不確定的部分可以先修正；也可以先建立，再到 Studio 裡調整。**

自動辨認的效果會受到原始文件排版與照片品質影響，工具不會取代維護者對路線資訊的確認。

## 實際例子：內湖大邱田

我們用現有的[大邱田 Google 文件路線書](https://docs.google.com/document/d/1K2PiA76lwXmpWKRZNgBkL5PeoVjs9kyY2sy4yyMBtoQ/edit)測試：下載成網頁 ZIP 後，直接交給 Studio 轉換。

| 內容 | 轉換結果 |
| --- | ---: |
| 區域 | 2 區 |
| 岩壁與石頭 | 22 面／顆 |
| 路線 | 49 條 |
| 岩壁照片 | 46 張 |
| 自動描出的 Topo | 33 條路線 |

交通與警示資訊也被整理進岩場資料；另外 13 張交通照片和 2 張配置圖沒有被當成岩壁路線照片。

再把作者的 57 張原始照片一起選進來：46 張路線書照片裡 29 張自動換成原圖（路線書裡的照片多半裁切、縮小過，一樣認得出來），都放在對的岩壁；剩下的是起攀點特寫和只有路線書才有的照片，沒對到的 28 張原始照片不會放進來。

這次主要需要人工完成兩件事：

1. 上攀區有 14 條路線集中在同一張表格，需要分配到 6 面岩壁。
2. 將手繪的岩壁配置圖對準地圖，再調整牆線。

**我們希望省下的是重複輸入的時間，留下的是維護者對岩場的了解。** 這是一次實測結果，不代表每份路線書都會得到相同的自動轉換比例。

## 三個步驟，把路線書轉進來

### 1. 準備你已經有的檔案

| 路線書類型 | 如何準備 |
| --- | --- |
| Google 文件 | 「檔案 → 下載」成 Microsoft Word（.docx）或網頁 ZIP |
| Microsoft Word | 直接使用 .docx |
| 網頁 | 儲存完整網頁，連同圖片資料夾一起選入，或包成 ZIP |
| PDF（有文字的） | 直接選 .pdf：讀文字，字比內文大的行當標題，「1) 路線名 *** F6b」「1 - 路線名 F6b」開頭的行當一條路線（下面的說明、「F.A.」首攀一起收）；PDF 裡的照片不會取出，另存成檔案一起選入。掃描的 PDF 沒有文字，讀不了 |
| 紙本 | 先取出文字貼進轉換文字框；照片另存檔案一起選入，必要時用 AI 協助整理 |
| 原始照片（選用） | 有路線書照片的原圖（沒畫線、比較清楚的那些）就一起選入，Studio 會自動換上 |

**不用先重新排版。** 如果文件原本用標題區分岩壁、用表格列出路線，通常更容易辨認。

### 2. 匯入並檢查預覽

在 [Climbio Studio](https://climbio.app/studio/) 選「轉換路線書」，再選「選路線書的檔案」。

Studio 會產生一份可編輯的大綱和轉換預覽。先確認區域、岩壁、路線與照片的數量是否合理，並查看標示出來的問題。

常見狀況包括：

- **路線還沒分到岩壁**：可在大綱的路線表格補上「岩壁」欄位；也可以建立後在路線表格移動。
- **找不到照片**：確認原本路線書引用的圖檔也一起選入。
- **岩壁名稱辨認錯誤**：在大綱裡修改標題，再看預覽結果。

如果文件結構太複雜，按「複製給 AI」，就能把整理提示與目前的大綱貼到 ChatGPT、Gemini 或 Claude 協助調整。AI 應只整理原文、不自行補造路線資料；建立前仍要自己核對。

確認後按「建立」。Studio 會把路線書照片上的紅線轉成 Topo；一起選了原始照片時，先找出每張路線書照片是哪一張原圖拍的，換成原圖，再從兩張的差異描出路線和 Bolt。

### 3. 補充、確認並發佈

建立後，可以繼續在 Studio 裡：

- **區域名稱**：調整岩壁、石頭與區域的名稱及分組。
- **區域圖**：使用有 GPS 的照片建立地圖；沒有 GPS 時，也能用「示意圖」對照原本的手繪配置圖調整牆線。
- **路線清單**：分配路線、排序、補上漏掉的說明。
- **路線圖**：檢查或修正 Topo，補上 Bolt 和確保站。
- **發佈**：不用登入，將 Guidebook 公開放進 Climbio 的開放資料集（`climbio/crags`，CC BY-SA 4.0），取得公開網址及分享網址。

之後有新路線或資料修正，直接更新同一本 Guidebook 再發佈；**分享網址不必跟著換。**

## 之後找到更清楚的原始照片，也能補上

許多路線書只有縮小或畫過紅線的照片。若之後找到同一次拍攝的原始照片，可在這本 Guidebook 使用「匯入照片」。

Studio 會配對原圖與已匯入的路線書照片：路線書的照片裁切、縮小、調過亮度都認得，同一面岩壁換個位置拍的照片不會被誤認。配對成功且已有 Topo 時，會用原圖取代，原本的線條照對位搬到原圖上；原圖如果有 GPS，也能補充地圖資訊。還沒描 Topo 的照片匯入時先保留，按「路線」→「從照片描路線」時再從標記與原圖的差異描出路線並換上原圖。

差異太大的照片可能無法自動配對，需要人工處理。再次發佈後，原有公開網址不變，收過這本的紅點貓下次打開時自動更新。

若你已經有符合 Climbio 格式的岩場站，也可以從 Studio 首頁「匯入岩場站」，再繼續補照片和維護內容。

## 不只是換一種方式看路線書

轉成 [Climbio 公開格式 v2](../format/README.md) 後，資料不必綁死在單一編輯工具或網站上。其他支援這個格式的 Viewer、App 或岩場網站也能使用；在紅點貓中，岩友可以查看 Topo、使用支援的離線資料，方便在岩場閱讀。

**讓路線書變得好用，也讓長年累積的資料更容易被保存和延續。**

## 開始前，你可能會想知道

**需要懂程式或 AI 嗎？**  
不需要。先匯入，Studio 會自動整理；AI 只是遇到複雜文件時的選用工具。

**要註冊帳號才能試嗎？**  
不用。使用電腦版 Chrome 或 Edge 開啟 Studio，專案資料保存在這台電腦的瀏覽器或指定的專案資料夾；需要公開時直接使用「發佈」。

**會改掉原本的路線書嗎？**  
不會。轉換是根據現有文件建立新的 Guidebook，不必修改原始文件。

**別人寫的路線書也能公開嗎？**  
公開前要確認文字與照片的使用權利，並保留應有的作者署名與來源。Studio 發佈採 **CC BY-SA 4.0** 授權；沒有取得適當授權的資料，不應直接公開。

**排版很亂，還值得試嗎？**  
值得先看預覽。工具會列出辨認有問題的地方；不一定要一次修完，更不需要因此重新打過所有路線。

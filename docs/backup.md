# 本地資料、備份與復原

## 使用者流程

岩點貓與紅點貓的照片、牆面、岩場、路線、收藏和攀爬紀錄，先存在自己的裝置。介面只提供需要的操作：「備份資料／復原資料」（岩點貓）與「匯出／匯入」（紅點貓）。兩款 App 共用一個暱稱，可從設定修改。

- **岩點貓**：備份產生 `.climbio` 完整檔案，包含牆面、照片、岩點、路線、攀爬紀錄與設定；復原前確認，再將資料還原到這台裝置。
- **紅點貓**：匯出時勾選岩場，保存對應的照片、Topo 與攀爬紀錄。匯入本機 `.climbio` 或 ZIP 檔案時，先顯示岩場清單，由使用者勾選要匯入的項目；覆蓋既有岩場前先提示。
- **換手機**：把檔案帶到另一台裝置，使用「復原」或「匯入」；也可透過「我的裝置」交換資料。配對時兩台都核對四位數，以後兩台同時開啟「我的裝置」且在可互相直連的同一網路時自動雙向同步，不是背景同步。確認新裝置的內容無誤前，請保留舊裝置的資料。
- **附近交換**：傳給朋友的內容以勾選的牆面、岩場或 Topo 為限；個人完攀紀錄、收藏及設定不會隨分享一起交給朋友。只有「我的裝置」配對成功後，個人收藏、攀登紀錄及必要的裝置權限資料才會同步到自己的裝置；刪除不會同步，攀登紀錄只增不減。兩款 App 共用暱稱，但分別配對。

## 實作與舊資料相容（開發者）

完整備份由 `appkit/backup.mjs` 與 `appkit/collection-backup.mjs` 管理；`appkit/backup-ui.mjs` 處理選檔、進度和確認。還原前檢查 App、版本、資料表及設定範圍，準備資料後再寫入 IndexedDB 交易。失敗時中止操作並保護既有資料。備份不含可重新下載的模型與快取。

備份只有本機 `.climbio` 檔，沒有雲端備份、也沒有 Google Drive 的支援。公開分享與個人備份分開，備份檔不能當公開分享網址使用。

相關測試：`tools/manual-backup.test.mjs`、`tools/redpoint-backup.test.mjs`、內部 e2e 案例。下一階段需測試一般匯出／匯入／備份／復原全程沒有額外帳號或授權畫面。

# 3D 牆

用多張照片重建的牆，在岩點貓裡跟一般的牆一樣看線、定線。打開的方式有兩種：連結 `/hold/?m3d=<牆 id>`（牆 id 是 16 碼亂數），或在「找牆面」照岩館點（Studio 發佈的 3D 牆都是公開的，跟各站的公開牆面列在一起）。

## 打開

- 第一次打開連結：下載這面牆的資料包（在 Climbio 的開放資料集 `climbio/walls3d`，經 `/p/<牆 id>/` 讀），在這台建一面牆，之後在首頁、離線都打得開。模型、面標籤存在 Service Worker 的大檔快取，App 更新不用重下載；`wall.json` 每次都等網路拿最新的（不因網路慢改用存的舊版，舊版指向的模型、面標籤可能已經換掉），離線才用存的。
- 牆的「照片」是正面快照，岩點外框是岩點投到快照上的範圍：首頁卡片、路線小卡、分享的圖片都從快照畫。
- 看線、定線時快照換成即時的模型（`wall3dkit/stage.js`）；回到牆面頁（路線卡片）就關掉 3D、釋放 WebGL，牆面頁跟 2D 的牆一樣只有快照。
- 隱藏的面（懸空物，和在 Climbio Studio 隱藏的）不畫、點不到；被裁切平面切掉的也是（岩點的像素除外，見下一條）。岩點標成不是岩點、大部分在隱藏的面上，或中心被 Studio 的切線切掉，就不算這面牆的岩點。
- 裁切平面：模型外緣是破碎的鋸齒，牆又是幾個大平面組成的，所以用平面切，切口在每一面牆上都是直線、只在轉角轉折。岩面模型不看岩點，把牆面擬合成幾塊平面牆板（完整的 3D 平面，仰角也算；一個分面跨過轉折的沿轉折切開），相鄰兩塊的 3D 交線是轉角線。地面：全牆一個水平面切在最低那顆岩點的下緣再往下 1/4 顆；沿牆腳的每塊牆板各切一條直線，相鄰兩塊在轉角線上共用同一點，每條只作用在自己那塊牆板的範圍；轉角點的高度在牆前抱石墊的頂端、牆腳破口最深處之上，不高過兩側最低岩點的下緣再往下 1/4 顆（再高會穿過牆腳的破洞，破洞變成牆緣的缺口）。底邊是一條連續的折線，在每塊牆板上筆直、只在轉角轉折。每塊牆腳牆板再加一個牆前切面（`front`），切掉牆前比切口高的墊子，岩點、站在前面的別塊牆板都讓開。天花板也是水平面（不切到岩點）。地面、天花板不照三角面藏：分面時牆腳常被分進地面，照三角面藏會把牆腳挖成鋸齒。懸空物（離牆面超過 3 顆岩點寬的、只靠細細一段連著牆的、切完以後跟牆不相連的碎塊）在建模時自動隱藏。其他外緣（兩側、上緣）每段大致直的邊擬合一條直線、放在最內側的凹口上，外面凸出的三角形切掉（只往內收，碰到岩點中心就讓開）；左右不切（轉角牆跟有岩點的牆連在一起，切開很怪），要切的在 Studio 沿轉角畫直線。發布的資料包都已烘焙：這些切面已經切進模型，`frame.planes` 只剩之後在 Studio 切的直線。
- 自動跟新版（跟 2D 公開牆一樣：打開牆、回到前景時問，同一面牆至少隔 5 分鐘）：Studio 每次發佈都是新的版本編號；這面牆的岩館清單（找牆面同一份）裡同一面牆的最新版，沿著它 `patch.json` 的 `parent` 往回找得到這台的版本，就換成新版（`w.pid` 換掉，舊的記在 `w.was`，舊版編號的連結也認得這面牆），接著照下一條重做快照與外框；路線、修點留著，舊版的模型快取沒有別的牆用就清掉。
- 資料包換過（重新輸出、在 Studio 改過）：打開牆面時在背景重做快照與岩點外框，做好了重新打開這面牆（已經在看線、定線就原地換上新的快照、照新尺寸重排）；路線、修點留著。這台存的牆記著資料包的樣子（`w.m3d`：模型、哪幾面隱藏、裁切平面、哪幾顆不是岩點），不一樣才重做。

## 看線、定線

跟 2D 的牆一樣（返回、標題、左右滑換線、編輯的 ×／難度／✓、角色、手順），差別：

- 進定線一條還沒有點的新線：從整面牆飛近（0.7 秒），飛到最近定的那條線（自己的、有點、出線最晚）的路線視角；還沒定過就是牆的中央、照片的高度填滿畫面，一進來就能選點。
- 底圖：看線灰階、定線暗彩（選了第一個點才調暗），路線上的岩點是原色、加一點左上方的側光（凸出的形狀更立體），外圍一圈角色色的光暈（看線、定線一樣）。光暈是畫面上的後製：路線岩點畫成遮罩（被牆面擋住的不算；量體上裝的別的岩點算進量體，不繞著每個洞發光），輕微模糊後取覆蓋率一半的等高線當修圓滑的岩點形狀，光暈照大模糊的覆蓋率從這條線往外漸淡，內外圈都平整、不跟著一格一格的邊，放大縮小都一樣寬；兩顆靠在一起的岩點，中間的縫不算岩點，兩圈光暈在縫裡疊在一起；兩顆貼在一起（沒有縫）時，交界兩側各一小段（約 4 個螢幕點，越靠交界越亮）畫成自己的光暈色，兩圈光暈接起來（另畫一張岩點編號圖找交界）。量體是面數為中位數 5 倍以上的岩點。
- 點岩點用射線：射線沿路穿過的岩點裡，點在它外框裡的選外框最小的（跟 2D 的牆一樣）；外框不看遮擋，被前面的牆或大岩點擋住的岩點也點得到。都不在外框裡就選射線打到的第一顆，打到牆面就找附近看得到的岩點中心。
- 鏡頭像沿著牆走的人：一直保持水平（不低頭、不抬頭、不歪頭），牆的直線一直是直的。打開牆面時算一條**軌道**：沿正面的左右軸每 10 cm 一格，牆面（不含岩點）水平法向的面積加權和與平均深度，平滑 0.5 m（離正面最多轉約 63°），就是每一段牆朝外的方向和位置；轉角變成一段柔和的彎。走近的目標不是畫面中央打到的那一點，而是中央視線跟這個平滑牆面的交點：打到突出的岩點或凹進去的洞都一樣，左右滑時鏡頭不會上下、前後跳（打不到牆時照樣不動）。放大、拖曳是沿著預先定好的路線走，像 2D 一樣平移：鏡頭自己記住三個數——沿牆的左右位置 x、看的高度、放大倍數 Z。左右照畫面中央那條線打到平滑牆面的位置（一比一跟手），上下只照手指移動的量（斜著看時打到的高度會變，畫面會上下飄），捏合只改 Z。路線照牆腳算：離地 40 cm 內的牆面每 10 cm 取深度中位數、平滑 0.5 m，就是牆在地上的走線（明德是 V 字形，兩邊各朝外約 45°）；牆的方向是走線的垂直方向，再平滑 0.8 m、往右偏約 9°，左右滑時視角跟著牆慢慢轉，放大縮小不轉角度。鏡頭的距離從人眼高度附近（眼睛往下 50 cm 到往上 30 cm）最前面那層牆面算（頭頂上的外傾不算，鏡頭走得進洞前面），是正面到牆中心的 1/√Z（最近 12%），看高處、低處時再往後退到那一點在畫面上下緣內；高度從正面的高度隨著走近換到拍照時手機的高度。兩端各有 1.5 m 的進場段（從最外側的岩點往內算）：越接近盡頭，鏡頭自動走得越近（至少 4 倍）、角度收回到接近正對那段牆（只偏約 6°），最左邊走進洞前面看清楚洞裡的點和內角。一直保持水平，看上看下不轉頭，移動畫面框（移軸）讓目標留在畫面中央。裁切放大只看 Z，左右滑時畫面比例不變。明德沿路線取樣量過：每顆岩點在自己的高度左右滑一整趟，2、3、5 倍時分別只有 8、5、2 顆看不到。跟 2D 一樣，畫面裡不露出牆外：上下照鏡頭到目標的水平距離算出畫面上下緣的高度，畫面比牆高就置中（上下留邊），不然上下緣不超過牆的上下緣，上下緣中間從鏡頭打出去的線也要打得到牆；左右在畫面中間、牆頂、牆底三個高度上，畫面左右邊緣打出去的線都要打得到牆（用模型打，斜切的角也這樣消掉）。打不到就往畫面中間推到剛好打得到，只有再推會把岩點推出畫面另一邊時停住（不漏點）。這時露出的牆外畫成牆面顏色（貼圖裡不鮮豔、不暗的像素各色版取第 65 百分位，照底色模式換算），看起來像牆面延伸，不是黑色。平滑牆面的深度取每一段最靠近鏡頭的那層（第 95 百分位，往兩側 0.5 m 取最大），凸出來的側牆、牆端前面也站得住，鏡頭不會貼到牆上。點兩下縮回、換線時回到正面的鏡頭。自動取景（路線視角、選到小岩點）只裁切不走近。
- 兩指跟 2D 一樣：中點移動是平移、捏合是縮放（鏡頭跟著走近）。沿牆鏡頭（成品包帶 walk）的兩指同向左右移（中點橫移、兩指距離幾乎不變；電腦用右鍵或 Shift／Alt＋左鍵左右拖）是**調角度**：鏡頭繞看的那一點水平轉，半個畫面寬是 30°，最多 ±30°，轉過去會碰到牆（離牆面不到 30 公分、或中間隔著牆）就轉少一點；放手後保留，之後左右滑每個位置都帶著這個角度，換線、離開路線歸零。單指左右滑到盡頭還繼續滑，多出來的滑動自動當成這個調角度（內角那邊的岩點轉過去才看得到）；反方向滑先轉回正面再走（`Stage.endTurn`）。等 3D 載入的「3D 準備中」畫面示範這個手勢（手機是兩個圓點一起左右移；滑鼠是一個圓點左右移，文字說右鍵左右拖）。沒有沿牆鏡頭的舊資料包：兩指扭轉（電腦用滑鼠拖曳）是**偷看**：繞畫面中央對到的那一點轉、保持水平，扭轉的角度就是轉的角度，離軌道上的位置左右最多約 23°、上下約 17°，放手（扭轉時放開一指也算）在 250 ms 內彈回正對牆面的位置。一次手勢只做一種（一開始扭轉超過約 9° 就是偷看），走近和偷看不互相拉扯。偷看、走近、拖曳的途中，整面牆的岩點外框每格照新角度重投（每顆岩點預先挑出 64 個方向最突出的頂點，只投這些點取凸包，整面牆約 20 毫秒）。換線、離開路線、完成定線回到正面（完成定線飛回整條路線的視角）。看路線圖放大超過路線視角、或走近轉過角度時，起攀、完攀的膠帶和手順不畫（平面的標籤換角度會跑來跑去），回到路線視角再出現。
- 長按修點跟 2D 一樣進單點編輯：長按岩點，這顆照目前的角度變成多邊形外框，拖頂點、拖邊中點加點、復原、刪除；長按沒有岩點的地方補一顆：先給方框，放大到那一塊後從畫面依顏色描出岩點（跟 2D 偵測岩點描外框同一個方法，HoldKit 的 `boxToPoly`），方框長成岩點的形狀，再拖頂點微調；描不出來就留方框。不跑 MobileSAM。按 ✓ 時把多邊形投回模型：從這個角度看得到、落在多邊形裡的表面算這顆（貼圖像素逐點判斷，邊界照多邊形走），原本是這顆但落在外面的清掉；看不到的那側不動，要改就轉個角度再修一次。改岩點時兩指不轉角度。
- 修點記在那顆岩點上（`h.m3`：當時的相機位置與方向、多邊形在快照上的比例座標；`k: 1` 是只改跟牆的交界：AI 照顏色邊界貼的外框，多邊形蓋到的別顆岩點的面和像素都不動（裝在上面的 chip 照樣讓量體的光暈填過去），人修的沒有這欄，照舊可以把別顆的範圍拉過來）；套用（`applyEdit`，貼圖標籤）時描的點之間補成通過每個描點的平滑曲線（向心 Catmull-Rom，每段 4 點，`smoothPoly`）；烘焙切網格先把外框簡化（Douglas–Peucker，偏差不到外框對角線的 1%）再切：AI 貼顏色邊界的外框很密，每點都切、或補成平滑曲線，三角形會多好幾倍（貼圖標籤、光暈仍照密的外框）。點選後光暈的內圈是遮罩模糊 4 個螢幕點（`SHAPE_BLUR`）後的一半等高線，網格三角形、修點折線的鋸齒都修圓；存檔的外框是正面角度的；每次畫之前比對，只重套變了的岩點（先把那顆還原成原始的標籤，再套新的），所以復原、取消、刪掉都會跟著變，改的岩點再多也不會越改越慢。
- 資料包也可以帶修點（`wall.json` 的 `edits`：`[{ id, m3 }]`，Climbio Studio 長按修的；`m3.a` 是 Studio 畫面的長寬比）：載入時先套上，跟這台的修點合在一起，同一顆以這台的為準；簽章含 `edits`，改了就重做快照。

## 分享

分享的路線跟 2D 公開牆一樣上傳到 Climbio（第一次分享要先填簽名、同意條款）：路線存成同一種圖層片段（岩點與角色、手順、難度在路線節點裡，3D 牆另帶這條線用到的岩點的修點 `e`），每天跟其他公開牆的線一起匯出到開放資料集。連結是短連結 `/hold/?m3d=<牆 id>&rid=<路線 id>`。傳不上去（沒網路、這個站不能分享）時退回舊的長連結 `/hold/?m3d=<牆 id>&r=<路線>`：整條線（名稱、難度、岩點與角色、手順、修點）壓縮在 `r=` 參數裡，不用伺服器也能收。收到的人打開連結：沒有這面牆就先下載，收下修點（改他這面牆的那幾顆、沒有的補上），再加上這條線並打開。收到的線跟 2D 一樣不能直接改，改的時候另存一條自己的。刪掉傳上去過的線會一起從 Climbio 拿掉。

3D 牆不上傳到公開牆，也不參加公開路線。

## 沿牆走的鏡頭（`wall3dkit/walkcam.js`）

看起來是 3D、定線跟 2D 一樣簡單：像人站在岩壁下看一面能定線的牆，不是在看 3D 模型；手機（直式）、電腦（橫式）同一套規則。
- **視角**：畫面的長邊看到 67°（`PERSON_FOV`，跟 iPhone 直拿拍照的上下視角一樣）：手機直拿上下 67°、電腦左右 67°。相機本身照舊 50°（快照的視角），沿牆時畫面框比快照大、上下置中（`Stage.walkAlong`），WalkCam 的換算乘上同一個倍數（`fovK`）。
- **上下拖**：整個鏡頭升降（像人長高），一直平視牆面，不抬頭、不低頭。跟 2D 一樣，可用畫面的上下緣不超出這一段牆（畫面中間那半段寬的牆腳、牆頂，`vlim`）；只有為了看到畫面裡最低、最高的岩點才往外放（`WalkCam.vSpanLevel`）。畫面比牆高就置中。
- **左右拖**（`WalkCam.walk`）：一邊走一邊慢慢轉向要走的那邊（看前面），拖約一個半畫面寬轉到 30°（`YAW_LEAD`；每拖 0.6 個畫面寬轉掉剩下的 63%）。只走到內角、側牆前：牆線（左右平滑 0.3 m）跟正面左右軸的夾角超過 50° 的地方（`CORNER`，`WalkCam.corners`），再過去牆線就轉進側面、凸出來的量體裡，鏡頭跟著走會繞到牆的背面。走到盡頭再拖就原地轉頭（鏡頭不動），最多 90°（`HEAD_END`），看內角的側面；轉過去畫面中間、左右一半和左右邊緣都要還打得到牆（不轉到看見牆外，例如窄的圖案牆轉角），轉不動就停。上下拖的最高點另外用射線量：畫面上緣中間還打在前方的牆上的最高鏡頭高度（`WalkCam.vHead`；牆頂往外傾時估牆頂的 `vlim` 會太低，電腦版畫面跟牆差不多高時鏡頭會被夾死、看不到牆頂）。往回拖：先把頭轉回來，再邊走邊轉回去。
- **cave**（`WalkCam.caveOf`）：盡頭那一側還有牆線轉進去才走得到的岩點（cave）時，頭轉不動了再拖就走進 cave（拖 1.2 個畫面寬，鏡頭位置、方向一起漸變）。站位：先放在那些岩點中間，再往 cave 的開口退到四周牆面的中位距離約 1.3 m（`CAVE_DIST`），cave 裡的岩點要還看得到九成五；高度在頭頂上的岩點（屋頂）下 35 cm、最高到眼睛。在 cave 裡左右拖是原地轉身，範圍是畫面八成以上是牆的那一段連續方位（每 5° 量一次，避開 cave 的開口，`CAVE_COVER`）；往外那一端（左邊的 cave 是右端）轉到底再拖就退出來。上下拖在 cave 裡是抬頭低頭，範圍照 cave 裡岩點的仰角。
- **捏合**：靠近或拉遠。最遠 1.8 m（`PERSON_FAR`）；橫的畫面（電腦）上下看得到的比較少，最遠改成上下看到的牆跟直拿手機在 1.8 m 時一樣高（約 2.4 m），大螢幕左右看得更多。不為了每顆岩點都點得到而縮近：最遠、七成、四成五的距離都點不到才算點不到；cave 裡的岩點算「站在站位轉得到、抬頭看得到」，內角側面的算「盡頭原地轉頭轉得到」。
- **框住岩點**（`Stage.frameTo`）：cave 裡的岩點直接站到 cave 的站位、轉身抬頭對著它（`caveFrame`）；內角側面的岩點走到那一側的盡頭、原地轉頭對著它（`WalkCam.cornerPose`）；其他沿牆走過去。點選岩點、AI 拍檢查圖都走這裡。
- 鏡頭不走進往前凸、比眼睛矮的量體：過了停點往外直走時，左右 1 m 內（`STEP_BACK_W`，往外漸變）的岩點都要離鏡頭至少目前的距離，不夠就往後退。

成品包有 `walk` 時岩點貓用它（`Stage.walkAlong`），沒有的舊資料包照舊用軌道相機。下面第 3 條「塞滿畫面」的高度範圍只用在沒有人的模式的舊鏡頭。

1. **軌道**：牆腳附近（高度 10%～60%）的頂點投到水平面，用主曲線找出牆的水平走向（會轉彎，V 字、L 字內角、側牆都跟得上）。
2. **鏡頭在哪裡（固定距離）**：每段、每個高度量牆面離走向多遠，得到鏡頭那個高度的牆面線（σ 15 公分去雜訊）。看的方向是牆面線平滑 1 公尺的法線（轉角處慢慢轉），鏡頭站在牆面線往外 d（使用者捏合選的距離）的地方，看沿這個方向打到牆面的那一點：一直跟正在看的那段牆保持距離 d。內角那裡等距線會打結（兩段交叉）：交叉中間那一段，鏡頭從交叉點沿看的方向往前走到離看的那片牆 d 為止，所以會往角落裡走再出來，看的方向一路平順地轉、鏡頭不往回走（明德 2.6 公尺時每 5 公分最多轉 2°，往角落裡走約 0.6 公尺）。外角那裡鏡頭繞著走。**回程角度**：載入後在背景算好（沿牆每 10 公分在 ±30° 裡挑看得到最多「正常角度一路看不到」的岩點的角度，相鄰位置角度差也算代價、整條一起挑，再平滑 30 公分）。滑到左右的盡頭再往回滑時漸漸換成回程角度，到另一端再往回就換回正常角度；換的時候從當下的角度接著漸變（在同一端來回、還沒換完又碰到盡頭，角度不會一下跳到底）。繞點轉 δ 鏡頭橫移約 d·δ，會跟沿牆走一樣帶著畫面跑，所以回程角度（含切換的漸變）每走 1 公尺最多變 0.5／d 弧度：橫移最多是拖動的一半，畫面維持手指速度的 0.5～1.5 倍（2.6 公尺時換滿 30° 要走約 2.7 公尺）；兩指調的角度加在上面，總共不超過 ±30°。明德在 iPhone 量過：正常角度一路滑過去 30 顆看不到（多半被量體擋住），加上 ±30° 只剩 3 顆；只因為上下被擋才看不到的只有 3 顆貼地的腳點，所以不調上下角度。鏡頭只在牆面範圍（牆面高度夠的那幾段）裡走，外角那裡鏡頭移動超過牆面點的 1.5 倍就不再繞過去（會走到牆的後面）。拖動、捏合是精確跟手：每一格解出鏡頭沿牆的位置和高度，讓手指底下那一點（捏合是兩指中心底下那一點）留在手指下；附近解不到才照一般的速度走。鏡頭路徑照固定的參考高度算，上下拖時鏡頭只升降、左右的範圍也不變。
3. **距離固定、左右走到牆的盡頭**：左右拖的時候距離不變（畫面大小穩定比塞滿畫面重要），走到畫面左右邊緣碰到牆面範圍的端點就停；每種螢幕的視角不同，照同一條規則各自算。橫的畫面（電腦、橫拿的平板）的工具列是浮著的小膠囊，上下不留白：畫面上下左右都要是牆（不看到牆外，定線比較方便）。左右、上下能走到哪裡、最遠的距離照下面的「鏡頭的標準」。射線照沿牆鏡頭的視角（FOV、畫面比例）算，不讀相機當下的投影（進場動畫時裁切還在變）。塞滿畫面只管上下：Studio 烘焙時在幾個距離、沿牆每個取樣點用小張的離屏渲染找出「畫面上下都是牆」的鏡頭高度範圍，建成表（直的手機畫面比例 0.46、0.56、0.62），上面 20% 可以露出牆頂上方的空間，下面 14% 是工具列擋住的地方（最低的腳點停在工具列上面，點得到）。表是用烘焙時的鏡頭校正的，跟現在的路線（等距線、調角度）對不上、兩端特別明顯，所以岩點貓打開後改用模型打射線：沿牆每 10 公分、照目前的距離和角度，找出畫面上排、下排（直的畫面扣掉上面那兩塊）和左右邊緣中間都打得到牆的鏡頭高度範圍（左右緣是斜的，每一排都是一段，取交集，上下各留 3 公分），算過的存起來；左右從中間往兩邊走，到找不到這種高度的地方為止。這個範圍沿牆的變化有坡度限制（每走 1 公尺最多變 1 公尺，看前後 1.2 公尺），前面變低時鏡頭高度提早慢慢降，不會換格時一下被壓下去。塞不滿就停在中間。
4. **進定線**：新增路線時，3D 第一格畫成牆面卡片的樣子（快照的相機；卡片的圖長寬比跟快照一樣就是整張快照，不然是岩點範圍那一塊，照 object-fit 對齊卡片），飛到沿牆鏡頭的起點（`walk` 的 `intro`：三種畫面比例都塞得滿的最遠距離、最接近牆中央）；編輯頁本身不縮放，看得到的範圍同時從卡片的圓角框展開到全螢幕，畫面上只有 3D 在動（沒有 2D 的卡片圖疊著，不會有鬼影）。一路都是正軸的鏡頭：起點轉向卡片中心、視角縮到卡片的大小、畫面框平移讓卡片中心留在原處（平移不會拉斜），飛的途中平移慢慢歸零，視角等比例放大，位置、朝向跟著同一個進度；1.4 秒、慢慢起步慢慢停（cubic-bezier(.4, 0, .2, 1)）。展開途中牆面頁留在下面。3D 第一格和拿掉 2D 在同一個工作裡，不會先黑一下。第一次打開、模型還沒載好時，先蓋著「3D 準備中」（不能操作），好了才從 2D 的畫面飛進去。飛的途中不能操作。
5. **看線**：沿牆鏡頭直接走到框住整條路線的位置（中間對準路線岩點範圍的中間，距離剛好放得下，上下扣掉工具列和牆頂的留白，四周留 25 公分；轉角附近斜著看估不準，再投影到畫面上修正幾次，直到全部在留白以內），不用 2D 的縮放。定完線、換線時從現在的位置沿牆走過去（0.6 秒）；從路線小卡進看線時從 2D 的路線畫面飛進去。外框先換回正面的存檔、畫小圖。

### 鏡頭的標準

只看模型和岩點資料，不針對哪一面牆調參數；每種畫面比例照同一套規則各自算（窄的手機同一個距離左右看到的比較少，盡頭比較靠內），直的畫面的「可用畫面」扣掉上面 20%、下面 14%（邊界表的 top、bottom），橫的畫面是整個畫面。依優先順序：

1. **每顆正面牆上的岩點都點得到**：左右完整出現在可用畫面、中心離左右邊至少 8 公分（`HOLD_R`；拉得很近、畫面比 32 公分窄時，最多留可用畫面的 1/8）；上下只要中心離可用畫面的上下邊 3 公分（`HOLD_RV`），牆最上、最下那排岩點不必整顆進畫面，鏡頭不用為了它們露出牆外。四邊都是牆的範圍外還有岩點時，左右範圍往外延伸到最外側的岩點剛好完整出現在畫面邊上（`sRange`）；上下範圍在每個位置放寬到畫面裡的岩點都點得到：最低的中心停在可用畫面下緣、最高的停在上緣（`needCell`，跟四邊都是牆的範圍一樣有坡度限制，岩點進出畫面時範圍慢慢變）。牆端外面沒有四邊都是牆的高度，接著往牆中間最近那格的範圍。
2. **在第 1 條之內盡量不露出牆外**：只在上面延伸、放寬出來的那一段允許露出，而且只放寬到剛好需要；其餘地方四邊都是牆。
3. **最遠的距離**：牆上還有一段連續一個畫面寬的地方，走過去畫面四邊都是牆的最遠距離（`dFill`），不為了牆角、最外側的岩點拉近。進定線從這個距離開始。
4. **側牆上的岩點**（離那個位置、高度的一般牆面超過 0.6 公尺，`SIDE`）：不擴大範圍，標準是在 ±30° 內有一個角度點得到（兩指調角度、回程角度）。

### 鏡頭標準（改 3D 鏡頭要對照）

改到 `wall3dkit/`、`js/wall3d.js` 或 3D 的手勢時，照下面的標準自己確認（沒有自動巡檢；3D 的瀏覽器案例已移除，不靠人一格一格滑的做法是用真的手勢走完整面牆再量）：

- **岩點**：鏡頭模型逐顆檢查（`WalkCam.missedHolds`）：每顆找左右範圍裡讓它最靠近畫面中央的位置、高度對準它，經過實際的範圍限制後要完整出現在可用畫面（上下邊容許一個像素：高度範圍沿牆每 5 公分取樣），側牆的可以調 ±30°。最遠的距離（定線時看整面牆）要全部點得到；最近的距離只列出來參考（拉得很近時鏡頭會走進內角）。
- **手勢**：用真的觸控、滑鼠走完整面牆：往左走到底、在端點來回、上下滑到底和頂，往右同樣一遍，拉近再走一遍。每一格量**露出牆外**（可用畫面打 9×17 的射線，相鄰兩格以上打不到才算；鏡頭在四邊都是牆的範圍外，也就是為了最外側岩點延伸的那段，允許，另外列出）和**跳動**（牆面點的移動跟手指差超過 30 px；縮放時比對以兩指中心縮放的位置）。

**固定連結** `/studio/wall3d/#p=<公開版本 id>`：不選資料夾，從公開資料（`/p/<id>/` 的 `base-*`、`patch.json`）在瀏覽器私有檔案系統（OPFS，`wall3d-<id>`）重建工作檔接著精修，發佈是新的版本（`origin` 接在這一版後面）；同一版再開沿用上次的工作檔。沒有 `patch.json` 的舊版本打不開。

**Studio 3D 牆編輯器分兩個階段**（步驟列「模型」「岩點」，版面跟 Wall 編輯器同一套：右上復原、重做、存檔，下方工具列，選到岩點的動作列浮在工具列上方）：**模型**——切直線（C）、點牆面隱藏、點切掉的地方拿回切線，岩點不能點；**岩點**——點一顆是選它（亮起、動作列「修外框、刪除」），長按岩點是修外框、長按牆上補一顆；工具列「新增」（N，點牆上補一顆）、「手畫」（P，拖一圈成外框）；快捷鍵 X／Delete 刪除（已刪的再按是還原）、Enter 修外框（修的時候是完成）、Esc 取消、J／K 換下一顆（畫面由左到右）、Z 復原、Shift+Z 重做。還沒切過的牆一打開是「模型」，切過的（含接著精修的公開版本）是「岩點」。沒有合併、重描、待確認：3D 的岩點範圍是貼圖標籤加修點，不是多邊形。

原型頁 `proto/walk/?wall=mingde|dapao`（開發版從 `/p/<id>/` 讀資料包；本機讀 repo 根 `.proto-data/` 連到 Drive 的資料夾）；邊界表存在 `proto/walk/*-table.json`，加 `?cal` 當場重算。

## 成品包（Studio 烘焙，格式 `climbio-3d-wall/2`）

Studio 發佈的是**成品**，不是工作檔；岩點貓只讀不算。按「發佈」時 `wall3dkit/bakepack.js` 從工作檔烘焙（Chrome 裡跑，不用 Python）：

| 檔案 | 內容 |
|---|---|
| `wall.json` | 岩點（id、位置、不在的標 `off`）、軌道表、快照的相機與尺寸、正面岩點外框、授權；沒有分面、切線、修點 |
| `wall-<雜湊>.glb` | **標準 glTF 2.0**：隱藏的面、裁切平面外的部分已經拿掉（跨過的三角形沿平面切開），貼圖內嵌、不受光（`KHR_materials_unlit`），別的檢視器直接能開。頂點的兩端淡出放在自訂屬性 `_WALL_FADE`（別的檢視器忽略）；照牆板結構切齊過的模型（外緣已經是直線：沒有邊緣整理、沒有裁切平面）不淡出，淡出會把真的牆面換成一片平的顏色，看起來像糊掉 |
| `faces-<雜湊>.bin`、`labels-<雜湊>.bin`、`overlay-<雜湊>.bin` | 每個面、每個貼圖像素、每顆岩點覆蓋網格的岩點編號（deflate）；修點已經套進去 |
| `snapshot-<雜湊>.jpg` | 牆的「照片」（正面快照），手機不用自己渲染 |
| `walk-<雜湊>.json` | 沿牆走的鏡頭：軌道、牆面深度的格子、三種畫面比例的實拍邊界表、進定線停的位置（見上一節） |

岩點貓載入成品：不裁切（著色器不跑平面測試）、不套 Studio 的修點、不算兩端淡出與軌道、不渲染快照也不投外框（`stage.js` 的 `baked` 路徑）；這台自己的修點（`h.m3`）照舊在手機上套。舊的 `climbio-3d-wall/1` 資料包暫時還讀得動（走原本的路徑），重新從 Studio 發佈就換成成品。

Studio 的工作檔不動：資料夾裡的 `wall.json`（分面、切線、修點）、原模型是來回調整用的；發佈時烘出成品，也存一份在資料夾的 `成品/`，之後再發佈都從工作檔重烘。

## 資料包

3D 牆放在 Climbio 的開放資料集 `climbio/walls3d`（Hugging Face，CC BY-SA 4.0），網站不附任何 3D 牆資料。發佈就是公開、不認人（[open-versions.md](proposals/open-versions.md)）：Climbio Studio 的「3D 牆」精修頁按「發佈」（不用登入，文件不記擁有者；每次發佈是新的牆 id，`origin` 指到這台上一次發佈的版本，已發佈的 id 不能再改；這台發佈過的版本記在瀏覽器的 IndexedDB `climbio-wall3d`）：先把工作檔烘焙成成品包（上一節），再由雲端函式 `datasets` 放進資料集的 `walls3d/<牆 id>/`（大檔由瀏覽器直接傳給 Hub，沒改的檔案不重傳，網址固定、歷史在資料集的 git），並登記到索引 `datasets/{牆 id}`（type `wall3d`，記 `gym` 岩館名）。每個版本另有基底與 patch：`base-wall.json`（第一次發佈時的 `wall.json`，存在工作檔資料夾，之後沿用）、`base-<原模型>`、`base-<面標籤>`（內容相同的檔案 Hub 只存一次），和 `patch.json`（`climbio-3d-patch/1`：`parent`、隱藏的面、裁切平面、不是岩點的岩點 id、修點，只有最終決定，不記編輯過程）；岩點貓只讀成品，不讀這些。`index.json` 是入口（`{ climbio: 2, type: 'wall3d', id, name, gym, pack: 'wall.json' }`），成品包的檔案同一層，另有 `thumb.jpg`（找牆面的縮圖，選填）。`gym` 存在工作檔的 `wall.json`，發佈時填。下架只拿掉索引，資料集的歷史照舊。

牆 id 就是 Studio 登記的專案 id（16 碼），岩點貓照 `/p/<牆 id>/<檔名>` 下載（雲端函式 `projectFiles` 查索引後 302 轉到資料集的檔案，CDN 留幾分鐘；沒有這面牆或這個檔回 404）。找牆面跟 2D 的公開牆走同一套清單：發佈時雲端函式 `datasets` 把有岩館名的 3D 牆登記進 `shared/{牆 id}`（牆 id＝專案 id，`src` 指到 `index.json`，`root` 記是哪一面牆），再由 `gym-walls.js` 整理成 `gymWalls/{牆 id}`（`m3d: 1`、`hf` 是資料集裡的資料夾、`repo` 是 3D 牆的資料集倉庫，`n` 公開路線數、`t` 最後活動時間）和岩館索引 `gymIndex/all`；站的 `/w/gym/{岩館}.json` 把它們跟 2D 的牆一起列（項目的 `props.model` 是 `3d`，縮圖是資料夾裡的 `thumb.jpg`）。同一面牆（`root` 相同）的舊版本發佈新版本時拿掉入口，清單每面牆只列最新發佈的那一版。下載次數由 `projectFiles` 在讀 `wall.json` 時記在 Firestore `projectStats/{版本 id}`（每天一個計數，不記裝置、帳號、位置，CDN 命中的不算）。沒有雲端後端的站沒有 3D 牆。

工作檔由 3D 重建流程輸出（在 Studio 精修，發佈時烘焙成上一節的成品包），格式 `climbio-3d-wall/1`：

| 檔案 | 內容 |
|---|---|
| `wall.json` | 岩點（id、3D 位置、面數、不是岩點的標 `off: 1`）、貼圖空間的岩點標籤（每個貼圖像素是第幾顆，uint16，deflate 壓縮）、邊緣整理（只移外緣頂點，不補洞；烘焙過的已寫進模型、沒有這欄）、分面（`surfaces`：每個三角面是第幾面，uint8，deflate 壓縮；每一面的種類 main／wall／floor／ceiling／loose 與是否隱藏；裁切平面 `frame.planes`：每個 `{kind, n, d}` 留下 n·p ≥ d 那側，kind 是 floor／front（牆前）／ceiling／edge（外緣拉直）／cut（Studio 的切線），有範圍的另有 `bounds`（最多 4 個 `[n, d]`，只切每個都 ≥ d 的範圍））、上方（用地面校正過水平）與正面方向、參考相機位置、授權 |
| `model-<雜湊>.glb` | 模型與貼圖 |
| `faces-<雜湊>.bin` | 每個三角面屬於第幾顆岩點（uint16） |

明德的牆面另外照牆板結構切齊：牆面擬合成幾塊平面牆板，相鄰牆板的交線是接縫，外框是牆板跟地面、天花板、兩端的交線（沒有岩點的地方可以往內收成跟對邊平行的直線）；原模型外框附近 30 cm 的牆面漸漸壓回牆板平面，再沿外框切開，切口落在牆板的邊上；網格不到外框的地方用建模照片投影的平面補（每點取看得到它的 5 張照片的加權中位數，避開遮擋，亮度照旁邊原貼圖校正，放進原貼圖用不到的空間），都沒拍到的用那塊牆板的牆面顏色；岩點照原網格、不切，不在任何牆板上的標 `off`。被照片分割切成兩塊的 volume 合回一顆（相鄰兩顆的交界在頂面上、色相相同、都凸出牆板 2.5 cm 以上；中間隔著一小段沒標的同色凸出面也算相鄰；灰黑白的不自動合併），留面積大的那顆，另一顆標 `off`，其他岩點的 id 不變。

切法確定沒問題後，烘焙把裁切和隱藏做進模型：整個在裁切平面外、在隱藏面上的三角面刪掉，跨過切面的沿平面切開（貼圖、岩點標籤照舊對得上；岩點的面照檢視器的規則讓開），切完 `frame.planes` 清空，模型自己就是乾淨的，檢視器不用再切；刪掉的 Studio 拿不回來。分面在重建流程補上（懸空物預設隱藏，地面切在最低岩點下面，天花板由裁切平面切），哪幾面要留、沿哪裡切直線、哪幾顆不是岩點在 Climbio Studio 的「3D 牆」改（[studio-design.md](studio-design.md)），只改 `wall.json`。同一面牆重新輸出用同一個 id，舊的連結照樣能開；同一個模型重新輸出時 Studio 改過的照舊。牆面內容（模型、貼圖、岩點）以 CC BY-SA 4.0 公開，署名 Climbio；程式在 Wall3DKit（`wall3dkit/`，AGPL-3.0-or-later，見它的 README）；`wall3dkit/vendor/three.js` 是 three.js 與 three-mesh-bvh（MIT）打包成的單一模組，授權在 `wall3dkit/vendor/three-LICENSE.txt`。

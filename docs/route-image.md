# 路線圖與標示

程式在 `routekit/`（見 `routekit/README.md`）。

- 路線岩點只用顏色區分（起攀綠、手點藍、腳點黃、完攀紅），不用線條樣式。沒有「不限腳」選項。
- **路線圖**（分享的圖和看路線頁一樣；編輯路線時才畫外框方便點選）：
  - 岩點不畫框，只保留彩色，其他地方灰階。
  - **署名**放右邊，後面接 logo（字級的 1.5 倍，跟署名對齊同一條中線）；只寫署名本身，不加「定線」等字，也不寫 App 名稱。卡片版靠照片右緣。沒有署名就只放 logo，往上靠近照片。沒登入也一樣（簽名是頭像選單「簽名」記在這台的，沒設過就沒有）。
  - **尺寸**（由分享目標決定，使用者不選）：限時動態 9:16（預覽和「圖片」；下方留空給 IG 的連結貼紙）、貼文 4:5（社群素材工具用），都是 1080 寬，以路線為中心裁切、岩點都在畫面內。圖上只有難度、名稱、署名和小 logo，沒有短句。
  - **風格**（自動選，使用者不選）：
    - 滿版：照片等比例放大蓋滿整張（以路線為中心取景，超出的裁掉），再依照片剛好塞進路線時的位置（上下留字的範圍之間）算出四條邊緣，邊緣內側淡出一圈暗線，整張像貼了井字形的暗框，路線的岩點壓在暗線上面不被壓暗；路線太寬、滿版放不下（照片放大到路線塞得下，高度填不滿上下留字之間的範圍）時用卡片。上下黑色漸層，左上大大的難度（Barlow Condensed 粗斜體）、下面一行名稱（Noto Sans TC Black）。
    - 卡片：照片模糊放大當底（縮小再一倍一倍放大做出來的模糊，Safari 的畫布不支援 filter），圓角照片放中間；照片上方難度（Outfit）＋名稱，照片右下方署名。
  - **分享預覽**：換路線或簽名時，先畫出畫面再產圖，新工作不用等待舊產圖工作；相同內容共用進行中的工作，已完成圖片立即取用快取。等待字型時不保留大畫布，過時工作不繪製、不覆寫目前預覽，也不改動目前的載入或錯誤狀態。
  - **字型**從 Google Fonts 載入（只下載用到的字；改名成「cb …」，不影響介面的字型），載不到就用系統字型。
  - **底圖兩種**（只在畫面上看，分享的圖一律灰階；進看路線圖從灰階開始、進定線從暗彩開始（選了第一個點才調暗），上方的圓鈕切換，不記在這台；路線小卡、收線卡片固定灰階）：**灰階**、**暗彩**（飽和度降到 45%、亮度 72%：牆不會暗得像沒開燈，其他岩點的顏色認得出來，路線岩點的原色是整張唯一鮮豔的；iPhone 的畫布沒有濾鏡，逐點算一次存起來）。路線岩點都是原本的顏色。
  - 灰階：先把暗部往上提（screen 疊 38：越黑提越多、亮的幾乎不動，牆上沒選的黑色岩點不再黑得像路線上的黑點，路線岩點用原色放在上面才認得出來），再壓到固定亮度範圍、上一層冷灰（`liftTint`，路線圖、小卡、收線卡片、示範共用）。每條路線都用同一個底：路線頁、牆面頁的路線小卡、收線畫面的卡片、分享的圖看起來一模一樣，小卡排在一起整齊，轉場也不會有色差。
- **起攀／完攀標示**（參考 IFSC 世界盃貼膠帶）：
  - S／T 小圓形標籤，只寫一個字母，放在岩點外面；圓和字不要太大。
  - 一段同色膠帶從岩點邊緣接到圓：膠帶整個寬度都從岩點外緣接出，只壓進一點點，不留空隙、不蓋到岩點、不穿過岩點；短邊貼齊岩點邊緣，方向跟那段邊緣垂直，不對著角落貼。
  - 方向：起攀斜往下約 45°（好幾顆起攀時從起攀群中心往外，上面那顆往上斜）；完攀水平（左右都可，差不多時放右邊），接在側邊靠上（大圓角的岩點往下找邊緣垂直的地方），不能往下；都不要正上正下。
  - 自動避開岩點（照外框判斷，路線岩點最優先）、其他標籤和照片邊緣（圓和膠帶一定在照片裡：伸出照片會被畫面切掉，這比蓋到旁邊的岩點更不能接受）。
  - 腳點用黃色短膠帶，與起攀、完攀的膠帶同寬，長度較短（14 單位，起攀／完攀接線至少 24 單位）；平直切口，不加圓形標籤。短邊緊貼岩點外緣、不留縫，從邊緣向外延伸，不壓進小腳點，自動避開其他岩點、標籤和照片邊緣。
  - 螢幕上縮放時標籤跟著照片放大，位置不能變。

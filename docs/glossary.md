# 名詞

同一個字在不同地方不能有不同意思。改名或加功能前先對這份。

## 工作區（`studio/`）

| 名詞 | 意思 | 程式裡 |
|---|---|---|
| **Wall** | 工作區：整理室內牆面的岩點外框（自己的照片、或自己在岩點貓公開的牆），修好後發佈、更新公開牆面，不管路線 | `studio/wall/` |
| **Crag** | 工作區：戶外岩場的指南 | `studio/crag/`，專案 `ws: 'crag'` |

## 組合的 `type`（發佈的包、公開格式 v2）

| `type` | 意思 | 誰發佈 |
|---|---|---|
| `walls` | 一間岩館的牆面（一組牆） | Wall、岩點貓的分享 |
| `guidebook` | 一本指南 | Crag |
| `room` | 牆面組合裡的一個分區 | Wall |
| `site`、`directory` | 站、總目錄 | 雲端函式 |

## 岩館（venue）

- **`gym`（小寫、字串）** 一律是「岩館」這個場地：岩館字串 `岩館#標籤#分區`、`/w/gym/{岩館}.json`、`gymWalls`、`gymIndex`（岩館的牆面索引）。
- 它**不是**組合的 `type`（岩館的牆面組合是 `walls`）。

## 其他

- **牆（wall）**：一張牆面照片加上岩點；`view` 是它的畫面，`layer` 是疊在上面的路線。
- **牆的檔案**：一面牆發佈時的 `{牆 id}.json`（畫面）、`.jpg`（照片）、`.thumb.jpg`（縮圖）、圖層；岩點貓用 `RouteKit.wallFiles` 組。縮圖一律在包裡，Climbio 不存。
- **包（pack）**：公開發佈的一組檔案，放在開放資料集，網址 `/p/<包 id>/<路徑>`。
- **指南**：Guidebook，岩壁、分區、路線的樹。

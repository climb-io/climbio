# 果凍岩點貓

說明卡上會動的岩點貓。App 只用在操作示範；新增牆面與完攀用照片裡的岩點變成貓，見 [holdcat.md](holdcat.md)。手機 App 與[獨立預覽](../design/brand/motion-preview/README.md)共用 `js/mascot-motion.js` 的路徑變形、耳臉收斂與時長；`tools/brand-icons.mjs` 從 [hold-cat.svg](../design/brand/cats/hold-cat.svg) 產生內嵌模板。

## 造型

- 只有一隻：保留 Logo 的不規則外圍岩點輪廓、萊姆綠前層 `#A4DC2A`、深綠背層 `#709F39`、鏤空耳朵、白臉、五官、下方螺絲孔。外緣可以拉長、壓扁、鼓起、回彈，但不另畫一套貓。
- 收回岩點：耳朵逐步縮入本體；白臉連同眼睛、鼻子朝面部中心聚攏縮小並消失，最後只剩**無耳無臉、由 Logo 身體衍生的岩點**（保留雙層與螺絲孔）。停穩約 400ms，再由外層場景退場。
- **不用**：T 型岩塊、舊版單色斜放岩點、一般三角形貓頭、終點還露出貓耳、臉突然跳切、每個情境各畫一隻貓。
- 所有變形都是動畫中的暫態，要回到一致的幾何；不能把變形後的臉存成 Logo 衍生版。

## 結構

1. **身體**：前層輪廓＋背層厚度＋螺絲孔。位移、旋轉與局部曲線變形並用；起跳前壓扁、起跳時拉長、落地橫向攤開，再用 1–2 次衰減回彈回到 Logo 比例。
2. **耳朵與臉**：與身體同一座標系、跟著身體動，耳朵可以延遲、眼睛可以先看。收場時往面部中心收攏，不是只把整張臉設成透明。
3. **道具**（路線卡、掃描框、放大鏡、小岩點）：只輔助，不改品牌輪廓；拿掉道具角色仍成立。

用 SVG group transform、分離的耳臉動畫，加上相同拓樸的少量 path 關鍵影格；不引入 3D 或角色框架，不靠整張 SVG 旋轉縮放假裝果凍。

| 動作 | 變形 |
| --- | --- |
| 伸懶腰 | 身體縱向約 1.3–1.5 倍、橫向略收，耳朵與五官跟著上移 |
| 吃飽鼓起 | 身體水平約 1.15–1.3 倍、縱向略壓，臉仍可辨識 |
| 果凍彈跳 | 起跳前壓扁 → 起跳時拉長 → 落地攤開 → 兩次衰減回彈 |
| 左右探看 | 外緣傾斜、前後層輕微延遲，視線先於身體改變 |
| 岩點化 | 耳朵縮入 → 白臉、眼睛與鼻子朝中央收攏 → 只剩無耳無臉岩點 |

## 情境

App 只用 `tour-in`、`tour-out` 與操作示範中段的 `view`、`set`、`repair`；其他情境只在獨立預覽。

| 情境 / key | 動作 | App 裡 |
| --- | --- | --- |
| 導引出場 `tour-in` | 無臉岩點軟化，彈起並長出耳朵、白臉與五官，約 3 秒 | 操作示範各段開始、重播時從岩點展開 |
| 導引收場 `tour-out` | 小幅揮手，收耳收臉；952–2600ms 收斂，2600–3000ms 岩點停穩，3000–3400ms 外層退場 | 每段演示完自動播放，停穩後才顯示重播／下一段／離開；離開不再播一次 |
| 看路線 `view` | 身體斜伸、眼睛沿線上移，回彈歸位 | 操作示範中段陪同解說 |
| 點擊定線 `set` | 一側外緣像小爪探出，點亮一顆岩點後回彈 | 同上 |
| 長按修岩點 `repair` | 身體前伸、放大鏡看局部，收回點頭 | 同上 |
| 收到路線 `receive` | 身體受力壓一下、接住路線卡，回彈後點頭 | 只在預覽 |
| 掃描岩點 `scan` | 輕微果凍呼吸、掃描框走過；分 `running`、`success`、`empty`、`error`、`cancelled`，只有成功才歡呼 | 只在預覽 |
| 記錄 `record` | Sent：壓扁起跳 → 落地圓鼓鼓 → 回彈 | 只在預覽 |
| 分享 `share` | 兩側外緣推送卡片、前伸回彈並揮手 | 只在預覽 |
| 找牆面 `find-wall` | 左右張望，找到候選牆面後耳朵微豎 | 只在預覽 |
| `idle-stretch`／`idle-full`／`idle-bounce` | 伸懶腰打哈欠／小岩點飛來吃飽圓鼓鼓／壓扁跳起落地晃兩下 | 只在預覽 |

## 播放規則

- 短、單次：一般約 1.2–2.6 秒，導引變身約 3 秒；不原地無限跳。
- 每個 SVG 只有一個可取消的控制；重播、切頁、離開前景、元件隱藏與移除時清掉 RAF 和延遲工作，不留孤兒 timer。
- 不遮擋右下 `+`、主要按鈕、路線照片或重要資訊；角色 `pointer-events: none`。
- `prefers-reduced-motion: reduce` 時不做彈跳、Morph 與位移；導引中的岩點貓保持靜止。
- 動畫不能取代真正的載入、成功、失敗處理。
- `hold/sw.js` 把 `js/mascot-motion.js` 納入同版本快取；動畫不下載設計原稿、不依賴 Firebase。

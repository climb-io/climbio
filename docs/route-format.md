# 公開資料的網址

分享出去的路線、公開的牆、找牆面的清單都用 Climbio 公開格式 v2（規格見 [format/README.md](../format/README.md)、詞彙見 [format/VOCABULARY.md](../format/VOCABULARY.md)）：牆是照片畫面，路線是疊在牆上的圖層，站、岩館、總目錄是組合。這份只寫 Climbio 的站把它們放在哪個網址、怎麼收。

所有網址都是 `GET` 不用登入、回 `Access-Control-Allow-Origin: *`；連結是哪台伺服器就到哪台讀，沒有伺服器清單、不用 Firebase。怎麼上傳（分享）由各伺服器自己決定，不在格式裡。

## 網址

| 網址 | 內容 | 會不會變 |
|---|---|---|
| `/r/{照片編號}/{路線 id}/` | 路線連結（給人和連結預覽的 HTML 頁）；頁面轉進 App 前先用 keepalive 的 `fetch` 下載下面的 `route.json`（換頁後照樣下載），App 在它下載完之前讀同一個網址就併用同一個請求 | |
| `/r/{照片編號}/{路線 id}/route.json` | 這條路線的圖層，`href` 指到牆，`props.thumb` 指到牆的縮圖，`props.preview` 是極小預覽圖（`data:`，長邊 96） | 作者改了跟著換；快取一天 |
| `/w/{照片編號}/routes.json` | 這面牆公開的路線（最新 50 條）的圖層，`href` 是牆的畫面（照片、岩點），在開放資料集裡牆主人發佈的包（`/p/{專案}/{照片編號}.json`） | 有人分享就換；快取十分鐘 |
| `/w/{照片編號}/thumb.jpg` | 牆的縮圖：302 導向開放資料集裡的 `{照片編號}.thumb.jpg` | 不會變；快取一天 |
| `/climbio.json` | 站（組合 `type: site`）：`props.url`、`props.listed`，一間有公開牆面的岩館一項（`href` 是下面的岩館清單，`props.walls` 公開牆面數） | 快取十分鐘 |
| `/w/gym/{岩館}.json` | 岩館的公開牆面（組合 `type: walls`）：一面牆一項，最新的在前；`id` 是照片編號，`href` 是從哪裡收（`routes.json`；還沒有路線的牆是開放資料集裡的牆畫面），`props.thumb`、`props.routes` 給清單畫卡片 | 快取十分鐘 |
| `/dir/gyms.json` | 總目錄（組合 `type: directory`，只在總目錄那台）：各站的每間岩館一項，`href` 是那個站的岩館清單，`props.site` 站名 | 快取一小時 |

岩館是 App 岩館清單的簡稱，或 `岩館#標籤#分區`（第一段是岩館，後面是分區、教練等標籤，最多 30 字），網址裡用 `encodeURIComponent`。

路線自帶的外框（定線的人修過的岩點、自己畫的岩點）跟牆上那顆不一樣時，圖層寫一個帶 `props.route` 的標註，只用在那條路線；畫面上沒有的岩點是圖層自己的 `hold` 節點。路線的 `props.climbio:device` 是出線那台手機的代號，App 用它認出自己出的線。

## 收線

1. 讀 `route.json`（圖層），再讀它 `href` 指的牆和照片；每份先過 `validate`，圖層的 `on`、牆的 `id` 都要是連結裡的照片編號。手上已經有這面牆就不再下載照片。拿到圖層就先顯示 `props.preview`，牆和 `props.thumb` 的縮圖同時下載，牆到了就開始下載照片（沒有 `props.thumb` 的圖層等牆到了再讀牆的 `props.thumb`）。
2. 收下：手上有同一個 id 的路線以修改時間晚的為準；點和角色（`holds`）都一樣的是同一條線，留先出的。
3. 之後要不要再讀那台伺服器的更新由各 App 決定（Climbio 讀同一張照片的公開牆，見 sharing.md）。

## 找牆面

讀總目錄的 `/dir/gyms.json` 和自己站的 `/climbio.json`，同一間岩館的站合在一起；點開岩館讀各站的岩館清單，收一面牆讀那一項的 `href`：是圖層就再讀它疊的牆，是牆就直接收（沒有路線）。收下存成自己的一份，之後不再連回去。

Climbio Studio 的 Wall 發佈的牆：`href` 是發佈的包裡的入口（`https://<站>/p/<專案 id>/<檔>`，一般的公開網址，跨網域可讀），牆的照片在同一層。讀到 404 就通報站，站查過才拿掉。

## 總目錄（找得到別的站）

總目錄把各站有牆的岩館合在一起。主網提供一個（`https://climbio.app`），誰都能自己架。

- **登記**：`POST https://<總目錄>/dir/register`，內容 `{ "url": "https://<站>" }`。不用帳號、不用審核：總目錄去讀 `https://<站>/climbio.json`，通過 `validate`、`type: site`、`props.listed: true`、`props.url` 就是這個網址才收（別人不能替不相干的網址登記）；岩館清單只收同一個站的網址。App 打開時自動送（每台手機一週最多一次），架站的人不用做任何事；總目錄自己的站不送，由每天的複查列進去。
- 總目錄每天重新讀每一站：連續 7 天讀不到、或改成不列出就移除；有問題的站可以手動封鎖。
- 只收 https 的網域（不收 IP、localhost、內部網域）；同一站一天最多驗證 4 次，總目錄一天全部最多 200 次。
- 總目錄不在時，各站照常運作，找牆面只看自己的站。

## 安全

只收 `https`；每份都先過 `validate`；照片最大 10 MB、只當圖片解碼；不顯示對方伺服器的任何 HTML。

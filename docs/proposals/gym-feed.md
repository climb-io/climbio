# 提案：岩館與岩點貓共享牆和路線（保持簡單）

狀態：結論是**不新增任何機制**。需要的東西現有的系統都有（站與總目錄、公開牆、公開路線、自動登記、不用審核），見 [route-format.md](../route-format.md)。只補一份給岩館 AI Agent 看的簡短指南：[gym-agent.md](../gym-agent.md)。

## 對照

| 需求 | 現有的做法 |
|---|---|
| 岩館的牆讓岩點貓、紅點貓看到 | Studio 發佈公開；或自己架站提供 `/climbio.json`，`POST /dir/register` 登記（自動驗證、不用審核） |
| 岩友在這面牆定的路線 | 岩友按「分享」就公開（授權條款在畫面寫一次：CC BY-SA 4.0、署名暱稱），不逐條同意 |
| 岩館拿到岩友的路線 | 讀 `/w/<牆 id>/routes.json`，單條 `/r/<牆 id>/<路線 id>/route.json`（公開格式 v2） |
| 岩館的路線讓岩點貓看到 | 用公開路線寫入（作者金鑰簽章）發佈到同一面牆 |

## 不做

新的格式、webhook、另外的登記或審核流程。之後真的有岩館需要即時通知再提。

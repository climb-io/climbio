# 公開資料集與版本

公開發佈不依賴帳號或 Google 登入。Studio 的 3D 牆、2D 牆與 Crag Guidebook，發佈的內容是公開的開放資料；使用者須先核對內容與授權。

- 每次公開發佈產生新的專案 id。已發佈的版本不可原地覆寫；新版本由 `origin` 指到上一版，`root` 指到第一版，並以 `lineage` 記錄來源。
- 公開檔案儲存在 Climbio 的開放資料集，雲端函式 `datasets` 寫索引、公開網址與版本關聯；不以登入帳號識別擁有者。
- `/p/<專案 id>` 指向固定版本。世界清單按相同來源彙整並排序，讀者可以找到其他版本。
- 發佈與上傳採 App Check、網路來源限流、檔案數與大小限制；不要求使用者處理憑證。
- 不當內容可由管理者從公開索引隱藏。已公開的資料集內容與歷史不保證可撤回。

Guidebook 的具體更新、排序與讀取策略見 [Crag 公開版本](crag-open-versions.md)。

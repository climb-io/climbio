# 公開牆路線的裝置識別

公開牆不要求帳號。只有建立路線的裝置可修改或撤回自己的公開路線；其他使用者可以收下並複製為新路線，不能覆寫原作者的路線。

- 第一次向公開牆寫入時，在背景產生 ECDSA P-256 裝置金鑰，使用公鑰指紋 `kid` 辨識作者。
- 寫入請求由裝置簽章，雲端函式 `functions/device-key.js` 檢查簽章、時間與重放；公開路線的擁有者以 `k:<kid>` 記錄。
- 金鑰跟隨使用者手動備份與已配對「我的裝置」同步，使用者不用查看或管理。
- 避免濫用時使用 App Check、依網路來源與裝置的基本次數限制、資料大小上限；不增加使用者登入或審核介面。
- 公開牆照片與岩點進入開放資料集，路線本身存在 `wallRoutes`，不因某條路線更新就重新上傳牆照片。

詳見 [分享與同步](../sharing.md)、[備份](../backup.md)。

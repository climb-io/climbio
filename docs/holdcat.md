# 岩點貓

照片裡的一顆岩點照自己的形狀和顏色變成一隻貓，就是岩點貓。一次只有一隻：每顆岩點的形狀和顏色都不同，貓自然每次不一樣。程式在 `js/holdcat.js`，樣式在 `css/app.css` 的 `.hc-*`。

## 長相

- **畫法跟品牌 logo 一樣**（[hold-cat.svg](../design/brand/cats/hold-cat.svg)）：平塗、沒有描邊、漸層和陰影；身體後面有一層往右下錯位的深色背層當厚度；耳朵是圓頭三角形，中間鏤空；臉下面一個鏤空的螺絲孔（放得下才有）；白臉、兩顆眼睛和鼻子直接用 logo 的形狀。不加鬍鬚、腮紅、尾巴。
- **身體**：岩點外框取凸包、重新取樣再磨圓，保留大小、長寬和歪斜；顏色是這顆岩點的平均色（飽和度拉高，太白的壓暗一點，白臉才看得出來），背層是同色壓暗。
- **臉的位置依形狀**：接近圓的岩點臉在中間偏左上，直長的更上面；扁長的岩點（寬是高的 1.35 倍以上）臉在比較高的那一端。
- **大小**：畫面上太小的岩點變貓時跟著長大（腳踩在原地），大約 66 px 見方，最多放大 2.4 倍。
- **影子**：岩點離開原位時，原位留一塊模糊的影子蓋住照片裡同一顆（暗的掃描畫面較深，淺灰的路線圖較淡）。
- 演完一律變回原本的岩點。

## 新增牆面

分析畫面偵測結果回來後：

1. **浮出來**：岩點由上往下依序從照片浮出（約 1.5 秒），每顆帶果凍回彈（壓扁 → 拉長 → 小回彈）和一圈淡出的螢光綠外框，數字同時從 0 跳到 N。
2. **醒來**：每次隨機挑 5 顆偏大、接近圓的岩點（面積前 4% 的大塊 volume 不挑；彼此不擠在一起，不夠再補）一隻接一隻（間隔 0.22 秒）變成貓，眨眼、左右張望，再變回去（每隻約 2.6 秒）。角色外形依各自岩點外框產生；[五位主角設定](../design/brand/holdcats.md)只供角色設計參考，不再有內建示範牆的固定座標演出。
3. **一波亮光**：整面岩點的外框由下往上亮過去（約 0.7 秒）。

**變身**：岩點先被拉一下（壓扁、拉長），顏色化開成貓的身體（小岩點同時長大），耳朵冒出來、臉從中心浮上來、眨眼（約 0.65 秒）。變回去時耳朵縮回、臉往中心收（約 0.45 秒），跟[果凍岩點貓](mascot-motion.md)的岩點化一樣。

浮完就出現「定第一條線」，醒來和亮光不擋操作；新增牆面時醒來演完（減少動態效果時浮完）就自動進定線。重描、整理外框回來換外框時直接畫好，不重播、不打斷醒來；偵測到 0 顆不醒來；失敗不演。

## 完攀

看路線圖右下的完攀鈕是貓爪印（沒完攀：半透明深色底、白色爪印；完攀：萊姆綠底、深色爪印），路線名稱旁的完攀標記也是同一個爪印。

看線時按完攀鈕完攀且儲存成功後：

1. **蓋章**：完攀鈕壓扁再彈起來，往外擴散一圈萊姆綠。
2. **爪印壓下去**：看得到的畫面中間壓下一個大爪印（約 0.4 秒，壓下去再彈回）。爪印是沾滿止滑粉蓋上去的白色粉印：有顆粒感、邊緣毛毛的，旁邊一圈淡淡的粉塵，放在真實岩壁照片上也協調，不用卡通平塗。壓到的那一下，路線上的岩點一起震一下（先被壓扁再左右晃、越晃越小，約 0.7 秒，近的晃約 6.5 px、6.5 度），離爪印越遠越晚震、晃得越小，像震波傳出去。爪印停一下再淡掉，整段約 1.7 秒。完攀不變岩點貓，路線和岩點位置都不動。

取消完攀（再按一次完攀鈕）：按鈕輕輕縮一下變回深色，不演、不提示。儲存失敗不演，狀態還原。

## 共同規則

- 疊在照片上、點得穿（`pointer-events: none`），不擋任何按鈕。
- 手指一碰、切換路線、離開畫面、回到背景就收掉；分析畫面的浮出來是結果本身，不會被手指打斷。
- 系統設定「減少動態效果」時不演：分析畫面直接畫好全部岩點，完攀只看 ✓ 的狀態。

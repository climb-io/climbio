처음 사용하기

홈 오른쪽 아래 지구본의 ‘세계’를 열고 국가·지역·암장을 차례로 선택해 가이드북을 내려받습니다. 출발 전 필요한 토포를 열어 사진이 모두 저장되었는지 확인하고 비행기 모드에서 다시 확인하세요.

설치

레드포인트 캣은 PWA입니다. iPhone/iPad의 Safari에서는 ‘공유 → 홈 화면에 추가’, Android의 Chrome에서는 ‘설치’를 선택하세요. iOS에서는 브라우저와 설치된 앱의 저장 공간이 다를 수 있어 자료를 다시 내려받아야 할 수 있습니다.

암장 찾기

‘세계’에서 국가 카드, 지역 카드, 암장 카드 순서로 탐색합니다. Climbio에서 공개한 가이드북과 사용 가능한 OpenClimbing 데이터가 포함됩니다. 모든 암장이 등록된 것은 아니며 사진 토포가 없는 장소도 있습니다. 공유 링크, PC 수집 도구 또는 로컬 파일로도 자료를 가져올 수 있습니다.

오프라인 다운로드

가이드북을 선택해 사진·루트·사용 가능한 지도 자료를 모두 내려받습니다. 현장에서 볼 토포를 열고 빠진 사진 안내가 없는지 확인하세요. 실제로 저장된 콘텐츠만 오프라인에서 동작합니다. 신규 암장 검색, 웹 수집, 외부 길찾기에는 인터넷이 필요합니다.

암장 둘러보기

홈에서 암장 카드를 누른 뒤 벽을 선택하면 첫 토포가 열립니다. 좌우로 밀어 사진을 바꾸고 발자국 버튼으로 루트 목록을 엽니다. 지역 사진, 지도, 접근 안내는 원본 데이터가 있을 때만 표시됩니다.

토포와 3D 보기

사진의 루트 선이나 번호를 누르면 이름·난이도 및 원본에 있는 길이·볼트·초등 정보 등이 표시됩니다. 두 손가락 또는 두 번 탭으로 확대하세요. 선택된 루트가 없으면 좌우 밀기로 토포를 바꾸고, 루트를 선택한 상태에서는 루트가 바뀝니다. 일부 가이드북에는 3D 모델이 있으며 누락된 정보는 임의로 만들지 않습니다.

지도와 접근·길찾기

출처에서 제공하면 암벽 지도, 구역 사진, 접근 설명 또는 외부 지도 링크를 이용할 수 있습니다. GPS 좌표는 출입구나 암장 중심일 수 있으며 실제 루트 시작점이 아닐 수 있습니다. 현장 안전, 통제 구역, 날씨를 직접 확인하세요.

등반 기록

발자국 버튼으로 루트 목록을 엽니다. 각 루트의 발자국을 누르면 ‘안 함 → 완등 → 등반함 → 안 함’ 순서로 바뀝니다. 상태별 필터가 가능하며 기록은 기기에 저장됩니다.

정렬과 암장 합치기

홈에서 암장 카드를 길게 눌러 끌면 순서를 바꿀 수 있고 다른 암장 카드 위에 놓으면 모음으로 합칠 수 있습니다. 모음의 이름을 바꾸거나 분리해도 원본 출처는 유지됩니다. 모음을 삭제하면 기기의 관련 데이터가 없어지므로 먼저 백업하세요. 출처 관계를 기준으로 자동 합치기 후보를 제안할 수도 있습니다.

수집과 가져오기

레드포인트 캣 수집 도구

방법 A: Climbio 공유 링크를 엽니다. 방법 B: 데스크톱 Chrome의 레드포인트 수집 도구로 theCrag·OpenClimbing 등 지원 사이트를 모은 후 휴대전화와 동기화합니다. 방법 C: .climbio 또는 ZIP 파일을 가져옵니다. 개인 수집은 다른 사람의 콘텐츠를 공개 재배포할 권리를 의미하지 않습니다.

공유

배포 권한이 있는 가이드북과 토포는 링크로 공유할 수 있습니다. 자신의 자료는 Studio를 통해 공개하고, 개인적으로는 파일이나 친구 간 직접 전송을 이용하세요. 재배포 권한이 없는 외부 개인 수집은 공개할 수 없습니다. 사진·글·토포의 저작권과 출처를 확인하세요.

친구와 직접 전송

같은 Wi-Fi에서 두 기기가 서로 직접 연결할 수 있도록 한 뒤 ‘+ → 친구에게 보내기’에서 사람과 암장 또는 토포를 고릅니다. 상대가 수락하면 저장되며 등반 기록·설정·기기 키는 전송하지 않습니다. 받는다고 ‘세계’에 공개되지도 않습니다.

내 기기 동기화

자신의 두 기기에서 동기화를 열어 같은 네 자리 코드를 확인하면 암장·토포·개인 수집·등반 기록을 교환합니다. 이후에도 서로 직접 연결할 수 있는 동일 네트워크에서 두 기기가 동기화 화면을 동시에 열어야 합니다. 백그라운드에서는 동작하지 않으며 삭제는 동기화되지 않습니다.

백업과 기기 변경

설정에서 암장을 선택해 .climbio 파일로 내보내고 새 기기에서 가져옵니다. 사진·토포·등반 기록을 확인한 뒤 기존 기기의 데이터를 정리하세요. 이미 저장된 내용을 덮어쓸 때는 안내를 확인하세요.

업데이트와 저장 공간

저장한 자료는 기기에서 먼저 표시합니다. 일부 출처는 인터넷에 연결되면 새 버전을 확인합니다. 사진 다운로드가 중단되었다면 온라인에서 다시 받아야 하며 글만 저장된 상태는 완전한 오프라인 토포가 아닙니다. 사진과 3D 모델은 저장 공간을 많이 사용할 수 있으므로 백업하세요.

자주 묻는 질문

‘세계’에서 암장이 안 보이면 공유 링크, PC 수집 또는 파일 가져오기를 시도하세요. 현장에서 이미지가 열리지 않는다면 출발 전에 모두 내려받고 비행기 모드로 검사하세요. 모든 원본에 토포·지도·3D가 있는 것은 아닙니다. 수정 작업은 레드포인트 캣이 아닌 Studio에서 합니다.

추가 활용과 라이선스

Studio에서는 기존 Word·PDF·웹 가이드북을 변환할 수 있습니다. 자신의 암장 사이트에 Climbio 데이터 형식의 입구를 제공할 수도 있습니다. OpenStreetMap, theCrag, 사진 작성자의 출처 표시와 사용 조건을 지켜 주세요.

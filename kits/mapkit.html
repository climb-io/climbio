@climbio/mapkit · AGPL-3.0

MapKit

岩場的向量地圖，看也能編輯

看線上範例在 GitHub 看原始碼

這是什麼

把岩壁、步道、道路、區域、地名和救援點畫成清楚的向量地圖，名稱自動避讓，附比例尺與羅盤。可開關航照、等高線底圖，也能讓使用者改岩壁線與區域範圍。

能做什麼

1

地圖清楚好讀

標籤自動避讓，放大才顯示分區名稱，手機上拖曳、縮放、旋轉都順手。

2

底圖隨你開關

OpenStreetMap、航照、等高線可以各自開關；不開底圖、沒有網路也能顯示自備資料。

3

編輯有岩壁概念

拖曳頂點、畫線、反轉岩壁面朝向、復原重做，輸出標準圖層。

線上範例

安裝

npm install @climbio/mapkit @climbio/format

最小範例

import '@climbio/mapkit/element';
// <climbio-map view="map.json" lang="zh"
//   basemap="ortho" style="height:70vh"></climbio-map>
// 編輯：加上 mode="edit"，el.viewer.edit({ node })

授權與限制

AGPL-3.0。底圖圖磚來自外部服務，需要網路與標示來源；定位與上傳由你的 App 負責。

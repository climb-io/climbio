RouteKit

在牆面照片上看線、定線

看線上範例在 GitHub 看原始碼

這是什麼

把一張牆面照片加上岩點外框，就能畫出路線圖：路線岩點保留原色、其他變灰，標上起攀、完攀與出手順序。使用者點岩點就能組出一條路線，也能匯出原尺寸的路線圖。

能做什麼

1

看得清楚

路線的岩點是主角，其餘退成灰階，起攀、完攀、腳點用膠帶標示。

2

點一下就定線

點岩點加進路線、換類型或拿掉，起攀數量自動限制，還能記錄出手順序。

3

資料好交換

讀寫 Climbio 公開格式與圈點格式（RouteMake），不綁任何 App 或後端。

線上範例

安裝

npm install @climbio/routekit

最小範例

import { scene, RouteViewer } from '@climbio/routekit';
const s = scene(img, holds);   // 照片＋岩點外框
const route = { holds: { a: 's', b: 'h', c: 't' } };
new RouteViewer(canvas, { scene: s, route });

授權與限制

AGPL-3.0。只做取景與點選，縮放、拖曳要自己加；需要瀏覽器的 Canvas。要偵測岩點請另用岩點偵測工具。

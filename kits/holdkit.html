HoldKit

偵測框變成岩點外框與顏色

在 GitHub 看原始碼

這是什麼

拿到岩點的偵測框之後，HoldKit 幫你描出每顆岩點的真實外框、判斷它是什麼顏色、建議整面牆該裁哪一塊。外框還可以用 MobileSAM 再描得更貼，全部在你的程式裡完成，不綁任何 App。

能做什麼

1

外框貼著岩點

每個框各自分辨岩點和牆，抓不到時退回內切橢圓，結果一定有外框可用。

2

顏色名稱與同色判斷

把岩點的代表色換成「紅、藍、蒂芬妮」這類名稱，也能判斷兩顆是不是同色。

3

可選的高精度重描

用 MobileSAM 把外框描得更貼，在瀏覽器或服務上都能跑；基本分析完全不需要它。

安裝

npm install @climbio/holdkit

最小範例

import HoldKit from '@climbio/holdkit';

const ana = HoldKit.analysis(photoCanvas, W, H);
const ctx = HoldKit.outlineContext(ana, boxes);
const poly = HoldKit.simplifyPoly(HoldKit.boxToPoly(...boxes[0], ctx));
const crop = HoldKit.cropSuggest(boxes, W, H);

授權與限制

AGPL-3.0，岩館與開源專案可以免費使用；打包進自己的前端時，那部分要照 AGPL 開放原始碼。照片到偵測框要另外做（Climbio 的 HoldScan 是 AGPL-3.0）；MobileSAM 重描可以在瀏覽器裡跑（第一次下載約 44 MB 模型），也可以自己架服務或使用 Climbio 的雲端加速。

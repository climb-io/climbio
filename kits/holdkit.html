HoldKit

偵測框變成岩點外框與顏色

在 GitHub 看原始碼

這是什麼

拿到岩點的偵測框之後，HoldKit 幫你描出每顆岩點的真實外框、判斷它是什麼顏色、建議整面牆該裁哪一塊。外框還可以用 MobileSAM 再描得更貼，全部在你的程式裡完成，不綁任何 App。

能做什麼

外框貼著岩點

每個框各自分辨岩點和牆，抓不到時退回內切橢圓，結果一定有外框可用。

顏色名稱與同色判斷

把岩點的代表色換成「紅、藍、蒂芬妮」這類名稱，也能判斷兩顆是不是同色。

可選的高精度重描

用 MobileSAM 把外框描得更貼，在瀏覽器或服務上都能跑；基本分析完全不需要它。

一起改善這項工具

想讓自己的 AI Agent 加入開發？把 Climbio GitHub 專案交給它，技術規格、授權和工作規則都從原始碼取得。

Crag3DKit

戶外 3D 岩場的播放與讀取

在 GitHub 看原始碼

這是什麼

把高斯潑濺或網格的岩場模型，加上疊在模型上的 3D 路線（帶編號、難度牌子），讓讀者站在步道上看整面岩壁、沿著岩壁走、點路線；也能從 Climbio 公開格式的檔案找出一個岩場的模型、各面岩壁和鏡頭。

能做什麼

1

沿著岩壁走

整段岩壁是一條連續的步道，左右拖就沿著岩壁走，第一次進來還有從全區飛進第一面的開場。

2

路線貼在岩面上

路線是模型上的 3D 折線，被岩壁擋住的地方查作者端算好的遮擋表，不畫、不標編號。

3

標準資料進出

吃 Climbio 公開格式的模型畫面、路線圖層和快照，不連任何後端；讀取與遮擋表在 Node 也能跑。

安裝

npm install @climbio/crag3dkit @climbio/format

最小範例

import { readCrag3d, mountCrag3d } from '@climbio/crag3dkit';
const crag = readCrag3d(docs, modelId);
const player = await mountCrag3d(host, { url: modelUrl, mime: crag.model.mime,
  marks: crag.marks, sight: crag.sight, nodes: crag.nodes, areas: crag.areas,
  poster: crag.areas[0].snapshot.href });

授權與限制

AGPL-3.0（內含 three.js、Spark，MIT）。只播放，不從照片建模、不編輯路線；需要 WebGL2 與 WebAssembly。室內 3D 牆請用 Wall3DKit，2D Topo 請用 TopoKit。

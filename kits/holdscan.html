HoldScan

照片裡的岩點，自動框出來

在 GitHub 看原始碼

這是什麼

丟一張岩牆照片，HoldScan 回傳每顆岩點的位置。可以直接在手機瀏覽器裡跑，照片不離開手機；也能自己架成服務，或在電腦上離線把固定的牆面照片分析成岩點資料。

能做什麼

1

手機上就能偵測

模型在瀏覽器裡執行，不需要伺服器，也不用上傳照片。

2

自己架服務

一個容器就能跑起來，不需要 Firebase，輸入大小可選，小岩點多的照片也抓得到。

3

離線整面牆分析

一行指令從照片得到岩點外框與路線資料，適合岩館自己管的固定牆面。

安裝

沒有 npm 套件：複製 holdscan/ 資料夾（瀏覽器版另需 holdkit/ort.js）

最小範例

<script src="holdscan/browser/holdscan.js"></script>
<script>
  HoldScan.warm();
  const { boxes } = await HoldScan.detect(canvas);
  // boxes: [[x0, y0, x1, y1, score], ...]
</script>

授權與限制

採 AGPL-3.0（偵測模型的授權要求）：透過網路提供改過的服務時，要公開你的原始碼。產生的岩點資料不受 AGPL 影響；只需要外框分析請用 HoldKit。

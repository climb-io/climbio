HoldScan

照片裡的岩點，自動框出來

在 GitHub 看原始碼

這是什麼

丟一張岩牆照片，HoldScan 回傳每顆岩點的位置。可以直接在手機瀏覽器裡跑，照片不離開手機；也能自己架成服務，或在電腦上離線把固定的牆面照片分析成岩點資料。

能做什麼

手機上就能偵測

模型在瀏覽器裡執行，不需要伺服器，也不用上傳照片。

自己架服務

一個容器就能跑起來，不需要 Firebase，輸入大小可選，小岩點多的照片也抓得到。

離線整面牆分析

一行指令從照片得到岩點外框與路線資料，適合岩館自己管的固定牆面。

一起改善這項工具

想讓自己的 AI Agent 加入開發？把 Climbio GitHub 專案交給它，技術規格、授權和工作規則都從原始碼取得。

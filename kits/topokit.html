TopoKit

岩壁照片上的 Topo 看圖與編輯

看線上範例在 GitHub 看原始碼

這是什麼

在戶外岩壁照片上畫出路線、bolt 和帶難度的編號牌，可縮放、點路線；也能讓使用者直接畫線、放 bolt、分岔，並輸出成標準圖層。

能做什麼

1

路線圖自動排版

編號、難度、名稱自動避開彼此與路線，路線擠在一起時會自動精簡。

2

看和編輯長一樣

編輯時看到的就是成品，畫線、放 bolt、分岔、復原重做都在同一張圖上。

3

標準資料進出

吃 Climbio 公開格式的照片與圖層，輸出也是圖層，不連任何後端。

線上範例

安裝

npm install @climbio/topokit @climbio/format

最小範例

import '@climbio/topokit/element';
// <climbio-topo view="topo.json" layers="routes.json"
//   bolts style="height:70vh"></climbio-topo>
// 編輯：加上 mode="edit"，el.editor.setTool('line')

授權與限制

AGPL-3.0。需要瀏覽器；上傳與版本歷史由你的 App 負責。室內岩點路線請用 RouteKit。

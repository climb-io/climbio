AppKit

PWA 常用的介面與工具，免框架

在 GitHub 看原始碼

這是什麼

AppKit 把做手機網頁 App 常遇到的事先做好：多語言、對話框與提示、照片匯入、系統分享、加到主畫面。純前端，不需要建置，也不綁後端。

能做什麼

1

照片匯入一步到位

讀拍攝位置、轉正、縮圖、重新編碼，一次完成，原始位置資訊不會意外外流。

2

一次只載一種語言

依手機設定載入單一語言包，離線也能切換，換語言不用重新整理。

3

不會壞掉的小工具

對話框取代瀏覽器內建的視窗；系統分享不能用時自動複製連結；儲存空間滿了也不丟例外。

安裝

npm install @climbio/appkit

最小範例

import { ui, photo, share } from '@climbio/appkit';

const p = await photo.prepare(file);   // 轉正、縮圖、取拍攝位置
if (await ui.confirm('使用這張照片？')) {
  await share.sendLink(url);   // 不能系統分享就複製
  ui.toast('已建立連結');
}

授權與限制

AGPL-3.0。需要自己提供品牌顏色變數（文件有一組可直接貼上的預設值）；附近交換與分享工具綁定 Climbio 本身，不屬於獨立使用的部分。

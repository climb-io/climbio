Crag3DKit

Play and read outdoor 3D crags

View source on GitHub

What it is

Take a Gaussian-splat or mesh crag model plus 3D routes drawn on it (with number and grade tags), and let readers stand on the trail, see the whole wall, walk along it and tap routes. It also finds a crag's model, walls and cameras in Climbio public-format files.

What it does

1

Walk along the wall

The whole wall is one continuous trail: drag left or right to walk along it, with an opening that flies from the whole crag into the first wall on the first visit.

2

Routes on the rock

Routes are 3D polylines on the model; where rock hides them, the author-side occlusion table says so, and the line and its number are not drawn.

3

Standard data in and out

Takes Climbio public-format model views, route layers and snapshots with no backend; reading and occlusion tables also run in Node.

Install

npm install @climbio/crag3dkit @climbio/format

Minimal example

import { readCrag3d, mountCrag3d } from '@climbio/crag3dkit';
const crag = readCrag3d(docs, modelId);
const player = await mountCrag3d(host, { url: modelUrl, mime: crag.model.mime,
  marks: crag.marks, sight: crag.sight, nodes: crag.nodes, areas: crag.areas,
  poster: crag.areas[0].snapshot.href });

License and limits

AGPL-3.0 (bundles three.js and Spark, MIT). Playback only: it does not build models from photos or edit routes; needs WebGL2 and WebAssembly. Use Wall3DKit for indoor 3D walls and TopoKit for 2D topos.

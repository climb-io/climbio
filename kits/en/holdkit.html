HoldKit

Turn detection boxes into hold outlines

View source on GitHub

What it is

Given detection boxes for climbing holds, HoldKit traces each hold's real outline, names its color, and suggests how to crop the wall. Outlines can be tightened further with MobileSAM. Everything runs inside your own code and is tied to no app.

What it does

Outlines that hug the hold

Each box separates hold from wall on its own and falls back to an ellipse when it cannot, so you always get a usable outline.

Color names and same-color matching

Turns a hold's representative color into a name like red or blue, and tells you whether two holds match.

Optional high-precision refinement

MobileSAM can tighten outlines further, in the browser or on a service; the basics never need it.

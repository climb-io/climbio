HoldScan

Find every hold in a wall photo

View source on GitHub

What it is

Give HoldScan a climbing-wall photo and it returns where each hold is. It can run right in a phone browser so the photo never leaves the phone, be hosted as your own service, or analyze fixed wall photos offline on a computer into hold data.

What it does

1

Detect on the phone

The model runs in the browser: no server and no photo upload.

2

Host it yourself

One container is enough, no Firebase needed, and a larger input size catches small holds in busy photos.

3

Offline whole-wall analysis

One command turns a photo into hold outlines and route data, ideal for walls a gym manages itself.

Install

No npm package: copy the holdscan/ folder (the browser build also needs holdkit/ort.js)

Minimal example

<script src="holdscan/browser/holdscan.js"></script>
<script>
  HoldScan.warm();
  const { boxes } = await HoldScan.detect(canvas);
  // boxes: [[x0, y0, x1, y1, score], ...]
</script>

License and limits

AGPL-3.0, as the detection model requires: if you run a modified version as a network service you must publish your source. Hold data it produces is not covered by the AGPL; use HoldKit when you only need outline analysis.

@climbio/wall3dkit · AGPL-3.0

Wall3DKit

Load, render, walk and bake indoor 3D walls

View source on GitHub

What it is

A gym wall reconstructed from photos, with every hold labelled on the model: load the pack, render the model underneath a 2D route-setting view, pick holds by raycast and walk the camera along the wall; on the author side, bake working files into a finished pack anyone can read as is.

What it does

1

Route setting as simple as 2D

The model renders under the 2D route-setting view, so zoom and pan work as before; holds are picked by raycast, hidden ones included, and their outlines are projected back to the front view for saving.

2

A camera that walks the wall

Drag sideways to walk, up and down to rise and sink, pinch to move closer; the camera turns smoothly at corners. Its ranges come only from the model and holds: every hold can be tapped, everywhere else shows wall on all four edges, worked out per screen aspect ratio.

3

Baked into standard files

The author side bakes cropping, hidden parts, hold fixes and the camera track into the finished pack: standard glTF 2.0 plus hold labels, so phones only read it and other viewers can open it too.

Install

npm install @climbio/wall3dkit

Minimal example

import { loadPack, openStage } from '@climbio/wall3dkit';
const pack = await loadPack(base);
const stage = await openStage(base, pack);
stage.mount(host);
stage.setView({ s: 1, tx: 0, ty: 0, bw: stage.snapW });
const id = stage.pick(x, y);

License and limits

AGPL-3.0 (bundles three.js and three-mesh-bvh, MIT). Reads packs and bakes them; it does not build models from photos; needs WebGL. Use Crag3DKit for outdoor 3D crags and RouteKit for walls on 2D photos.

TopoKit

View and edit topos on a crag photo

See the live demoView source on GitHub

What it is

Draw routes, bolts and number tags with grades on an outdoor crag photo, with zoom and tap-to-select. Users can also draw lines, place bolts and fork routes, and the result comes out as a standard layer.

What it does

1

Automatic label layout

Numbers, grades and names avoid each other and the lines, and simplify themselves when routes crowd together.

2

Viewing equals editing

What you see while editing is the final result; drawing, bolts, forks and undo/redo all happen on the same image.

3

Standard data in and out

Takes a Climbio public-format photo and layers and outputs a layer, with no backend involved.

Live demo

Install

npm install @climbio/topokit @climbio/format

Minimal example

import '@climbio/topokit/element';
// <climbio-topo view="topo.json" layers="routes.json"
//   bolts style="height:70vh"></climbio-topo>
// Editing: add mode="edit", then el.editor.setTool('line')

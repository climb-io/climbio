SourceKit

Toolbox for bringing outside crags into Climbio

View source on GitHub

What it is

A set of small helpers for sites, browser extensions and importers: shrink photos to a sensible size, trace routes from a topo photo, read crags and photos from OpenClimbing, and compute a stable id for any source. No framework required.

What it does

Routes from photos

Red pen, any pen color or white dashes can be traced into polylines, and even the numbers on route badges can be read.

Reads open crag data

Pulls crags and routes from OpenClimbing and OpenStreetMap, plus properly licensed topo photos from Wikimedia Commons.

One source, one id

The same crag gets the same id whether it was imported by the extension or the app, so saving again updates instead of duplicating.

Help improve this tool

Want to contribute with your own AI agent? Start with the Climbio GitHub project. Source code, technical requirements and licensing live there.

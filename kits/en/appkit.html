AppKit

Everyday PWA UI and helpers, no framework

View source on GitHub

What it is

AppKit handles what mobile web apps keep needing: multiple languages, dialogs and toasts, photo import, system sharing, and add to home screen. Pure front end, no build step, no backend lock-in.

What it does

Photo import in one step

Reads the shooting location, fixes orientation, makes a thumbnail and re-encodes in one pass, so location data does not leak by accident.

One language at a time

Loads a single language pack based on the phone's setting, switches offline, and needs no reload to change language.

Helpers that do not break

Dialogs replace the browser's built-in popups; sharing falls back to copying the link; a full storage never throws.

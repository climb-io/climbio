Climbio Format

An open interchange format for climbing data

View source on GitHub

What it is

A public JSON format that describes routes, holds and crags on a photo, a map or a 3D model, shipped with a JSON Schema and a validator. Any app or website can read and write it from the spec alone, with no Climbio server or account.

What it does

Built around views

Routes, holds and walls are marks drawn on a view, so it works the same on a photo, a map or a model.

Open vocabulary

The core structure is fixed; new route styles or fields need no spec change and no version bump, and unknown data is simply skipped.

Stable apart from changing

Photos and hold outlines can be cached forever; when a route changes, only its overlay layer is replaced.

Help improve this tool

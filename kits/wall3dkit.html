Wall3DKit

室內 3D 牆的載入、繪製、沿牆鏡頭與烘焙

在 GitHub 看原始碼

這是什麼

照片重建的岩館牆面模型，每顆岩點都標好在模型上：載入資料包、把模型畫在 2D 的定線畫面下面、用射線點岩點，鏡頭沿著牆走；作者端把工作檔烘焙成任何人都能直接讀的成品包。

能做什麼

1

定線跟 2D 一樣簡單

模型畫在 2D 的定線畫面下面，縮放、平移照舊；點岩點用射線，被擋住的岩點也點得到，岩點外框投回正面存檔。

2

沿著牆走的鏡頭

左右拖沿牆走、上下拖升降、捏合靠近，轉角處鏡頭平順地轉。範圍只看模型和岩點：每顆岩點都點得到，其餘地方四邊都是牆，每種螢幕比例各自算。

3

烘焙成標準檔案

作者端把裁切、隱藏、修點、鏡頭軌道都做進成品：標準 glTF 2.0 加岩點標籤，手機只讀不算，別的檢視器也打得開。

安裝

npm install @climbio/wall3dkit

最小範例

import { loadPack, openStage } from '@climbio/wall3dkit';
const pack = await loadPack(base);
const stage = await openStage(base, pack);
stage.mount(host);
stage.setView({ s: 1, tx: 0, ty: 0, bw: stage.snapW });
const id = stage.pick(x, y);

授權與限制

AGPL-3.0（內含 three.js、three-mesh-bvh，MIT）。只讀資料包、只烘焙，不從照片建模；需要 WebGL。戶外的 3D 岩場請用 Crag3DKit，2D 照片的牆請用 RouteKit。

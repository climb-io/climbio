@climbio/format · Apache-2.0

Climbio Format

攀岩資料的開放交換格式

在 GitHub 看原始碼

這是什麼

一份公開的 JSON 格式，描述照片、地圖或 3D 模型上的路線、岩點與岩場，附 JSON Schema 與驗證器。任何 App 或網站照規格就能讀寫，不需要 Climbio 的伺服器或帳號。

能做什麼

1

以畫面為中心

路線、岩點、岩壁都是畫在畫面上的標註，換一張照片或一張地圖照樣適用。

2

詞彙開放

核心結構固定，新增路線種類或欄位不用改規格、不用升版本，不認得的資料直接略過。

3

常變的和不變的分開

照片與岩點外框收下就能永久快取，路線改了只換疊在上面的圖層。

安裝

npm install @climbio/format

最小範例

import { validate } from '@climbio/format';

const errors = validate(doc);   // [] 就是合格
if (errors.length) console.log(errors.join('\n'));

授權與限制

Apache-2.0，沒有相依套件。驗證器只檢查單一檔案，跨檔案的放法與圖檔檢查要自己做；要畫畫面或編輯，用 Climbio 的其他元件。

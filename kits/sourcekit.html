@climbio/sourcekit · AGPL-3.0

SourceKit

把外站岩場轉成 Climbio 的工具箱

在 GitHub 看原始碼

這是什麼

做網站、擴充功能或匯入器時常用的一組小工具：照片縮到合適大小、從 Topo 照片描出路線、從 OpenClimbing 讀岩場與照片、為同一個來源算出固定的 id。不依賴任何框架。

能做什麼

1

從照片抽出路線

紅筆、任何顏色的筆、白色虛線都能描成折線，連號碼牌上的數字也讀得出來。

2

讀開放的岩場資料

直接讀 OpenClimbing 與 OpenStreetMap 的岩場、路線，以及 Wikimedia Commons 上有授權的 Topo 照片。

3

同一個來源，同一個 id

同一個岩場不論從擴充還是 App 匯入，都算出同一個 id，重存就是更新，不會重複。

安裝

npm install @climbio/sourcekit

最小範例

import { idOf, fitSize } from '@climbio/sourcekit';

idOf('osm:relation:123');   // 固定的 16 碼 id
fitSize(3200, 2400);        // { w: 1600, h: 1200 }

授權與限制

AGPL-3.0。描線是啟發式的，結果要讓使用者確認；號碼牌數字不是 OCR，字型不同會讀不準。

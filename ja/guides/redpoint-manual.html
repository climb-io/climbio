最初の使い方

ホーム右下の地球アイコン「世界」から岩場を探し、Guidebook をダウンロードします。出発前に必要な Topo の写真がそろっているか開いて確認し、機内モードでも読めるか試してください。

インストール

レッドポイントキャットは PWA です。iPhone／iPad は Safari の「共有 → ホーム画面に追加」、Android は Chrome のインストール機能を使います。iPhone ではブラウザーとホーム画面のアプリの保存領域が別の場合があり、再ダウンロードが必要になることがあります。

岩場を探す

「世界」では国のカードを開くと地域、その先に岩場カードが表示されます。岩場を選んで Guidebook を受け取ります。Climbio 公開データや利用可能な OpenClimbing データが中心で、すべての岩場・Topo が含まれるわけではありません。見つからなければ共有リンク、PC の収集ツール、ローカルファイルを使います。

オフラインに保存

岩場のダウンロードが終わると写真、ルート、地図が端末に保存されます。旅行前に写真を開いて未取得の画像がないか確認してください。最初の「世界」表示、新しい岩場の取得、インターネット経由のインポート、外部ナビには通信が必要です。

岩場の閲覧

ホームで岩場カードをタップし、岩壁を選ぶと Topo が開きます。複数の Topo は左右に切り替えられ、右下の肉球からルート一覧を開けます。交通情報・区域図は元データに含まれる場合だけ表示されます。

Topo と 3D

写真上のラインや番号をタップすると、名前・グレードや元データに含まれる長さ、ボルト、初登情報などが表示されます。ピンチ・ダブルタップで拡大し、未選択時の左右スワイプは写真、選択時はルートを切り替えます。一部の Guidebook には操作できる 3D モデルがあります。存在しない情報を自動で補うことはありません。

地図・アクセス・ナビ

データがある場合、岩壁・エリア・道の地図、アクセス案内、外部地図アプリへのリンクを使えます。座標は岩場や入口の目安で、必ずしも取り付き地点ではありません。天候、安全、立ち入り条件を現地で確認してください。

登攀記録

肉球ボタンでルート一覧を開き、各ルートの状態を「未登 → 完登 → 登った → 未登」の順に切り替えます。状態による絞り込みが可能です。記録はこの端末に保存されます。

整理と統合

ホームカードを長押ししてドラッグすると順番を変更でき、別の岩場カードに重ねるとコレクションにまとめられます。コレクションは名前の変更や分割ができます。元のデータと出典は保持されます。削除すると端末の写真・データが失われるためバックアップしてください。設定から出典関係に基づく統合候補を確認できます。

収集とインポート

レッドポイントキャット コレクター

方法A：共有された Guidebook のリンクを開く。方法B：PC 版 Chrome のレッドポイント収集拡張機能で対応する theCrag／OpenClimbing 等のサイトを取り込み、自分の端末同期でスマホに渡す。方法C：設定から .climbio または ZIP ファイルを読み込む。個人の収集物は公開再配布の権利を意味しません。

共有

権限のある公開 Guidebook／Topo はリンクで共有できます。自分が公開できる内容は Studio で公開し、非公開で渡す場合はファイルの書き出しや友達との直接共有を使います。外部収集物に再配布権限がなければ公開共有できません。写真や Topo の著作権を確認してください。

友達と共有

同じ相互接続可能な Wi‑Fi 上で双方がアプリを開き、ホームの「＋ → 友達に送る」から岩場や Topo と相手を選びます。受信者が承諾すると自分の端末に保存され、世界には公開されません。個人の登攀記録・設定・端末キーは渡りません。外部ソースの再配布条件にも従ってください。

友達と共有

自分の端末を同期

PC とスマホ等でプロフィールの「他の端末に同期」を開き、４桁コードを照合してペアリングします。岩場、Topo、個人の収集物、登攀記録が同期されます。以後も両端末が直接接続できる同じネットワークで「自分の端末」画面を同時に開く必要があり、バックグラウンドでは動作しません。削除は同期されません。

バックアップ・機種変更

設定から「書き出し」で岩場を選び .climbio ファイルを保存します。新端末では「読み込み」で復元したい岩場を選び、上書き警告を確認します。選んだ岩場の写真、Topo、登攀記録が含まれます。復元確認前に旧端末を消去しないでください。

更新・通信・保存容量

保存済みデータは優先的にオフラインで表示します。対応する出典は接続時に更新を確認します。写真の取得が中断したら通信環境で続きを取得してください。文章だけでは完全なオフライン Topo になりません。大きな写真・3D データの容量とブラウザーのデータ削除に注意してください。

よくある質問

世界に岩場がない場合は共有リンクやファイルを試してください。山で写真が開かなければ通信可能な場所で再取得し機内モードで確認します。Topo、地図、3D がない場合は元データが提供していません。公開共有のない個人収集物は権限を確認してください。編集は Studio で行います。

さらに活用

古い Word、PDF、Web のガイドブックは Studio で変換できます。自分の岩場サイトから Climbio 形式を提供することもできます。OpenStreetMap、theCrag、写真作者の出典と利用許諾を尊重してください。

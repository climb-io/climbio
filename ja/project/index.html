使い方

Climbio をジムのアプリに組み込む

使い慣れた AI Agent で、既存のジムアプリに課題の閲覧と作成画面を追加できます。別途の開発は不要です。ここでは考え方を説明し、技術仕様と組み込み手順は GitHub にあります。

AI Agent でアプリに組み込む

ジムのスタッフは 3 ステップだけです：1. 下の文章をコピー。2. いつも使っている AI Agent（Claude、ChatGPT、Codex など）に貼り付け。3. 聞かれたことに答える（壁の写真の場所 など）。Agent は先に壁を整え、次にアプリへ組み込み、あとで壁を更新するときも同じ手順で進めます。あなたの判断が必要なことは先に質問します。

まず https://github.com/climb-io/climbio/blob/main/docs/embed.md と https://github.com/climb-io/climbio/blob/main/docs/gym-agent.md を読み、私たちのジムを次の 3 段階で Climbio に組み込んでください：
1. 壁の準備：Climbio Studio（https://climbio.app/studio/wall/）で壁の写真をホールドのデータに整えて公開し、壁 ID を取得します。コマンドラインで作業するなら node tools/studio.mjs start gym <フォルダ> <写真…> を実行し、表示される次の手順に従ってください。ホールドは画像を見て確定するまで自分で確認し、迷ったら拡大して見直します。
2. アプリへの組み込み：既存のジムアプリに埋め込みページ（iframe または WebView）を置き、データは公式 URL のみ使います。ユーザーが課題を作り終えたら submit で送り、返ってきた routeId を自社のユーザーに対応づけて保存します。
3. その後の壁の更新：壁やホールドを調整したら Studio で同じ壁を再公開します（新しいバージョンになり、既存の課題はそのまま）。写真を差し替えた場合は新しい壁として新しい壁 ID にし、アプリの切り替え方を教えてください。
私が決める・用意するもの（壁の写真、ユーザーと課題の対応、バージョンを固定するか）は先に質問し、勝手に作らないでください。各段階が終わるたびに確認方法を教えてください。

まず AI Agent に組み込みガイドを読ませてください。手順は 3 つ：Studio で壁を整えて公開し、閲覧・作成画面をアプリに入れ、固定の壁 ID でルートを更新します。ルートをクライマーと共有したいジムに向いています。ユーザーとルートの対応はアプリ側で決め、Climbio は関与しません。

今できること

Hold Cat では課題の作成と共有、Redpoint Cat では岩場データのオフライン閲覧ができます。友達との共有、コレクター、Studio もデータの整理に役立ちます。機能は引き続き改善中です。

ジム運営者の方へ

自分で開発せずに、ジムのアプリにルート表示とルートセットを

壁の写真を Climbio に渡すと、ホールドをタップできる壁になります。それを今のアプリに組み込めば、クライマーはアプリの中でルートを見たり作ったりできます。アカウントや記録、データベースはそのままです。

実例を見るAI Agent に渡す指示をコピー

組み込むと、ジムに何が得られるか

開発は不要

ルート表示とルートセットの画面は用意済みです。アプリに埋め込みページ（Web なら iframe、ネイティブなら WebView）を 1 つ置き、壁の id を渡すだけです。

壁の整備は AI に任せる

壁の写真を 1 枚撮ると、Studio がホールドを検出し、AI が確認して公開します。スマホでもできます。壁を直したら同じ壁を再公開すれば、古いルートもそのまま使えます。

他の場所でも見つけてもらえる

あなたの壁はホールドキャットの「壁を探す」にも載り、ルートはアプリとホールドキャットの両方で見られます。二重に管理する必要はありません。

ユーザーと記録はそのまま

Climbio が預かるのは壁とルートだけです。ユーザーとルートの対応、完登の記録、コメントはすべてアプリ側で決めます。投稿はあなたのサイトが身元になり、鍵の申請も不要です。

実際に見る

ジムのアプリに組み込んだルートセットの画面です。壁のホールドをタップするとルートを作れます（デモなので保存されません）。ルート表示も同じ埋め込みページで、モードが違うだけです。

タップすると読み込みます（写真は約 2 MB）

一般のユーザーにも同じ壁が見える

公開した壁はホールドキャットにも載ります。クライマーはあなたのアプリを入れなくてもルートを見たり作ったりでき、ルートは両方に表示されます。

ホールドキャットを開く

進め方

  1. AI Agent が壁を整える：手元でホールドファイルにし、画像を見て自分で確認し、1 つの ZIP にまとめます。
  2. アプリに組み込む：ルートページに埋め込みページを置き、管理画面に「壁の公開」埋め込みページを置きます。スタッフが ZIP を入れて同意し公開すると、アプリは公開されたバージョンに固定します。
  3. ユーザーがルートを作る：作り終えたら送信すると、その壁に公開されます。アプリは返ってきたルート id を自分のユーザーと対応づけて保存します。

AI Agent に渡す

普段使っている AI Agent（Claude、ChatGPT、Codex など）に貼り付けてください。手順をすべて読んだあと、必要な写真や情報を 1 つのリストにまとめて質問するので、答えるだけです。公開する前には必ず同意を確認します。

まず https://github.com/climb-io/climbio/blob/main/docs/gym-onboarding.md を読み、その手順でうちのジムに Climbio を組み込んでください。最初に、私に用意してほしい写真と情報を 1 つのリストにまとめて聞いてください（何度にも分けないでください）。私が答えられないことは、作り話をせず選択肢とおすすめを示してください。

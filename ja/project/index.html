使い方

Climbio をジムのアプリに組み込む

使い慣れた AI Agent で、既存のジムアプリに課題の閲覧と作成画面を追加できます。別途の開発は不要です。ここでは考え方を説明し、技術仕様と組み込み手順は GitHub にあります。

今できること

Hold Cat では課題の作成と共有、Redpoint Cat では岩場データのオフライン閲覧ができます。友達との共有、コレクター、Studio もデータの整理に役立ちます。機能は引き続き改善中です。

最新の進捗

公開版の変更は GitHub で確認できます。予定や未完成の作業はプロジェクトの記録を参照してください。予定を完成済みとして表示しません。

公開開発の履歴

AI Agent でアプリに組み込む

まず AI Agent に組み込みガイドを読ませてください。手順は 3 つ：Studio で壁を整えて公開し、閲覧・作成画面をアプリに入れ、固定の壁 ID でルートを更新します。ルートをクライマーと共有したいジムに向いています。ユーザーとルートの対応はアプリ側で決め、Climbio は関与しません。
